# Exercise pictures

The SVG movement diagrams are original Life OS artwork. They illustrate general movements, not a personal prescription. Source technique references are linked from the picture viewer in `lib/exercisePictures.js`.

The ten JPEGs (five pairs) are unchanged copies from [Free Exercise DB](https://github.com/yuhonas/free-exercise-db), downloaded 29 October 2026. The upstream project identifies its exercise data and imagery as public domain and permits local use. Its [Unlicense](https://github.com/yuhonas/free-exercise-db/blob/main/LICENSE.md) is reproduced in `LICENSE-photos.txt`.

Original paths under `https://raw.githubusercontent.com/yuhonas/free-exercise-db/main/exercises/`:

- `Dumbbell_Floor_Press/0.jpg`, `1.jpg`
- `One-Arm_Dumbbell_Row/0.jpg`, `1.jpg`
- `Butt_Lift_Bridge/0.jpg`, `1.jpg`
- `Band_Pull_Apart/0.jpg`, `1.jpg`
- `Dumbbell_Bicep_Curl/0.jpg`, `1.jpg`

The local filenames replace the final slash with a hyphen. Photos are movement references; saved plan targets remain the source of repetitions, sets and loads. No third-party image server is contacted when using the app.
