Assignment Statement

A variable is a name that refers to a value. It is created using assignment statements.

>>> message = “Should I follow the data or my instincts?” >>> n = 92 >>> pi = 3.141592653589793

The left-hand side of an assignment statement has to be a variable name:

<variable name> = <some value>

● Names should be meaningful (for readability). ● They must begin with a letter ( a-z, A-Z ) or an underscore ( _ ). ● They can contain letters, numbers, or the underscore character. ● They can be any length. ● They are case sensitive ( myVariableName is different from myvariablename ). ● They cannot be one of the Python keywords.

What are the Python keywords?

In Python, we can type the following to see a list of Python keywords:

>>> import keyword >>> keyword.kwlist

False await else import pass
True break except in raise
None class finally is return

async elif if or yield

● Choose meaningful names instead of short names

– recordCount is better than rc

● Keep names short where possible

– Is idNumberOfAStudent too long?

● Be consistent

– e.g. use Camel Case (recordCount) or Snake Case (record_count) throughout

● You can begin a name with an underscore for special cases

– e.g. _maxRecords, or _internalData

Assignment Statement

You can assign a value to multiple variables at the same time:

>>> a = b = c = 7

>>> print( a, b, c ) 7 7 7

You can also assign multiple values to multiple variables at the same time:

>>> x, y, z = 1, 2, 3

>>> print( x, y, z ) 1 2 3

Expressions and Statements

An expression is a combination of values, variables and operators.

● It is evaluated by the Interpreter, which finds its value.

>>> 42

42

>>> n

92

>>> n + 2

94

Expressions and Statements

A statement is a unit of code which has an effect, like creating a variable or displaying a value.

● It is executed by the Interpreter. ● In general, statements don’t have values.

>>> n = 92 >>> print( n )

92

Multiple Statements on a single line

You can write separate statements on just one line by putting a semicolon character ( ; ) between them.

e.g. instead of:

>>> print( “Statement one” ) Statement one >>> print( “Statement two” ) Statement two

you can write:

>>> print( “Statement one” ); print( “Statement two” ) Statement one Statement two

Comments

Comments are notes which explain in natural language what the program is doing. They start with the # symbol.

● Everything from the # symbol to the end of the line is ignored by the Interpreter. ● They are excellent for explaining the function of code written in a script.

Python has many built-in functions; we’ve already seen print(), id() and type(). divmod() takes a dividend and divisor, and returns the quotient and remainder:

>>> divmod( 11, 4 )

(2, 3)

Here, we are asking Python to evaluate 11 divided by 4. 4 will go into 11 twice, with a remainder of three.

Built-in Python functions

Python also has function dir(). This can list all the names in the current “local scope” (more on those later). It can help us identify the objects and variables we can currently use.

>>> myVariable = 64 >>> dir()

['__builtins__', '__doc__', '__loader__', '__name__', '__package__', '__spec__', 'myVariable']

We can see our variable “myVariable”. We can also see a special Python object called “__builtins__”.

dir() can also be given the name of an object to examine. The following produces a lot of output! Let’s look at only a segment of it:

>>> dir( __builtins__ )

[ … 'dict', 'dir', 'divmod', 'enumerate', 'eval', 'exec', 'exit', … ]

It includes Python’s built-in functions. We can see “divmod” here.

● dir() can be useful for seeing what our code has created, and what is

available for us to use.

Order of Operations

Rule of precedence: PEMDAS

  1. Parentheses have the highest precedence, and can be used to force the expressions within them to be evaluated first.
  2. Exponentiation
  3. Multiplication and Division
  4. Addition and Subtraction

Operators with the same precedence are evaluated from left to right (except for exponentiation, which is evaluated from right to left).

String Operations

In general, you can’t use mathematical operators on strings, even if the strings appear to contain numbers.

Exceptions:

string1 + string2 performs string concatenation:

>>> first = ‘Cardiff ‘ >>> second = ‘University’ >>> first + second

‘Cardiff University’

string * integer performs repetition:

>>> ‘Spam ’ * 3

‘Spam Spam Spam ‘

Joining lines

When you want to write a long piece of code in a single line you can break that logical line into two or more physical lines using the backslash character ( \ ).

Therefore, when a physical line ends with a \ (and the backslash is not part of a string literal or comment) it will be coupled to the next physical line.
