What are Regular Expressions?

Also known as “Regex”. From regexforge.com:

● Regex is a powerful tool that allows you to search, match, and manipulate text

using patterns.

● Common uses:

– Validating user input: Ensuring emails, phone numbers, and passwords meet

specific formats.

– Searching and replacing text: Finding words or patterns in documents or

logs.

– Extracting information: Pulling key data from large text files, such as log

files or reports.

– Web scraping: Parsing HTML and extracting content from web pages.

Components

We can categorise the types of component found in Regular Expressions into three groups:

  1. Basic Matching: simple matching operations, such as matching just a single character, the start/end of a line, or one of a limited set of specific characters.
  2. Quantifiers: components which specify a quantity for each match (e.g. match a character with one occurrence, zero or more occurrences, a specific number of times, and so on).
  3. Metacharacters: more powerful, specific or utility-based functionality, such as being able to operate on a specific group of characters, matching a numeric character or a whole word, or detecting a word boundary.

Basic Matching Components

. Matches any single character, except a newline (\n)
[abc] Matches any character inside the brackets (here, a, b or c)
a-c Specifies a range of characters (here, a, b or c). For instance, “[a-c]” is equivalent to ”[abc]”.
[^abc] Matches any character not inside the brackets (here, not a, b or c). Equivalent to [^a-c]
^ Matches the start of a line
$ Matches the end of a line
a|b Logical OR; matches a term to the left OR right (here, a or b)

Example: regex “b|c” will match the first letter of “cat” or “bat”, but not of “mat”.

Quantifiers

a* Matches zero or more occurrences of the term on the left (here, a)
a+ Matches one or more occurrences of the term on the left (here, a)
a? Matches zero or one occurrence(s) of the term on the left (here, a)
a{n} Matches exactly n occurrences of the term on the left (here, a)
a{n,} Matches n or more occurrences of the term on the left (here, a)
a{n,m} Matches n (min) to m (max) occurrences of the left term (here, a)

Example: regex “e*” will match all the ”e” characters in ”meow”, ”meeow”, ”meeeow” etc. as a group (i.e. for ”meeeow”, there will be one match: ”eee”).

The regex “e{1,2}” will match only groups of one or two ”e” characters. In the string ”meeeow”, there will be two matches: ”ee” (characters 2-3) and ”e” (character 4).

Metacharacters

\ Escapes a special character (e.g. to allow use of literal $, ., * etc.)
() Matches a continuous group of characters (e.g. (ab) matches “ab”)
\w Matches any “word” character (i.e. alphanumeric, or an underscore). Equivalent to [a-zA-Z0-9_].
\W Matches any “non-word” character (not alphanumeric or underscore). Equivalent to [^a-zA-Z0-9_].

Example: regex “\$\w” will match one dollar character (because the ”$” is escaped with ”\”), followed by one alphanumeric or underscore character. In the string “$1.23 _ $2.34”, there will be two matches: “$1” and ”$2”.

Metacharacters (continued)

\d Matches any numeric digit. Equivalent to [0-9].
\D Matches any non-numeric digit. Equivalent to [^0-9].
\s Matches a whitespace, tab, newline, carriage-return, form-feed, or vertical-tab character. Equivalent to [\t\n\r\f\v].
\S Matches a non- whitespace, tab, newline, carriage-return, form- feed, or vertical-tab character. Equivalent to [^\t\n\r\f\v].
\b Matches a word boundary.

Example: regex “\b\d” will match one numeric character, but only if it occurs at the start of a new word (after a word boundary). In the string ”543 210”, there will be two matches: ”5” and ”2”.

The findall Method

The findall method extracts all matches from a string (the input string is not changed).

● Matches are returned within a tuple. ● All matches are non-overlapping.

Recall that we can create a raw string using r”<string>”; this is useful for regular expressions.

>>> string = "bz2, dz2, bzz2, bz3, bx2, af2, c92, C92"

>>> regex = r"[abc].2"

>>> re.findall( regex, string )

['bz2', 'bx2', 'af2', 'c92']

The match method identifies whether the regular expression matches the beginning of the string.

● If it is matched, a “Match object” is returned. ● If it does not match, None is returned.

re.sub( <regex>, <replace>, <input_string>, [ count=<count> ] )

The sub method returns a copy of input_string, where each match of the regular expression is replaced by the replace string.

● replace may also be a function (which processes each “Match object”). ● The optional keyword argument count can specify a maximum number of

replacements.

>>> string = "bz2, dz2, bzz2, bz3, bx2, af2, c92, C92" >>> regex = r"[abc].2"

>>> re.sub( regex, "MATCH", string )

'MATCH, dz2, bzz2, bz3, MATCH, MATCH, MATCH, C92'

>>> re.sub( regex, "MATCH", string, count=2 ) 'MATCH, dz2, bzz2, bz3, MATCH, af2, c92, C92'

re.split( <regex>, <string>, [ maxsplit=<count> ] )

The split method splits the input string around the regular expression matches,

and returns a list of these components.

● The optional keyword argument maxsplit can specify a maximum number of splits. ● After maxsplit is reached, the remainder of the string is appended to the list.

>>> string = "bz2, dz2, bzz2, bz3, bx2, af2, c92, C92" >>> regex = r"[abc].2"

>>> l = re.split( regex, string ) >>> l

['', ', dz2, bzz2, bz3, ', ', ', ', ', ', C92']

>>> "MATCH".join( l )

'MATCH, dz2, bzz2, bz3, MATCH, MATCH, MATCH, C92'

Let’s say we want to fetch all words beginning with an “a”, “r” or “t” within a string. We can construct a “test string”, and then begin to build our regular expression.

>>> test_string = “When shall we three meet again; In thunder, lightning, or in rain?”

● First, we want to match a word boundary (otherwise, we might match the letters

“a”, “r” or “t” in the middle of the string):

>>> regex = r”\b”

● Next, we want to match a single character from a our specific set of characters:

>>> regex = r”\b[art]”

A Small Example

● We can already test our regular expression to see what it returns:

>>> test_string = “When shall we three meet again; In thunder, lightning, or in rain?”

>>> regex = r”\b[art]”

>>> re.findall( regex, test_string )

['t', 'a', 't', 'r']

● This is only matching a single character; let’s add a match for any alphanumeric

character:

>>> regex = r”\b[art]\w”

>>> re.findall( regex, test_string )

['th', 'ag', 'th', 'ra']

● This is good, but we want one or more alphanumeric characters to be matched

after our chosen letters (not just one). Let’s specify the one or more quantity for our “\w” component:

>>> test_string = “When shall we three meet again; In thunder, lightning, or in rain?”

>>> regex = r”\b[art]\w+”

>>> re.findall( regex, test_string )

['three', 'again', 'thunder', 'rain']

● It works! We can now apply our regular expression to any string (and, therefore, any

document).

Raw Strings: a reminder

● What happens if we omit the r operator, and try our search once more?

>>> regex = ”\b[art]\w+”

>>> re.findall( regex, test_string )

[]

● There are no matches! This is because the word boundary character (\b) has

become an ASCII backspace (character 8); it wasn’t escaped!

>>> regex

'\x08[art]\\w+'

>>> regex[ 0 ]

'\x08'

Don’t forget to use raw strings (r”<string>”) when working with regular expressions!

● Are there any remaining issues? What about the fact we chose lowercase letters,

and the alphanumeric pattern (\w)? What would happen if we applied our regular expression to the string “Item three r123”, or to “Three r123”?

>>> regex = r”\b[art]\w+”

>>> re.findall( regex, “Item three r123” )

['three', 'r123']

>>> re.findall( regex, "Three r123" )

['r123']

# We don’t want r123...

# Perhaps we do want Three?

● We can choose alphabetical characters (“[a-zA-Z]” instead of “\w”), and we can add

uppercase letters to our second component (“[artART]” instead of “[art]”).

● It’s important to fully consider the design of a regular expression, and test it

thoroughly.
