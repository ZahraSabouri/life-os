The while statement

● While n is greater than 0, display the value of n and then decrement n. ● When n is equal to 0, display the word Blastoff!.

● This type of flow is called a loop because the second step (“n = n - 1”)

loops back around to the top (“while n > 0”).

● The body of the loop should change the value of the condition variable(s),

so that the condition becomes False eventually, and the loop will terminate.

● Otherwise, the loop will repeat forever, which is called an infinite loop.

break

● The break statement can be used to jump out of the loop.

break

● The loop condition is True (which is always true!) so the loop runs until the

break statement is executed.

● Each time through, it prompts the user with an angle bracket (“> “). ● If the user types “done”, the break statement exits the loop (and then the

statement “print( “Done!” )” after it is run).

● Otherwise, the program echoes whatever the user typed and then goes back to

the top of the loop.

The while statement

● This type of flow will loop forever, unless a statement within the loop’s body

causes the loop to end.

● The body of such a loop should contain a break statement, if statements

after the loop should be executed (or if the program is not designed to run forever).

continue

● The continue statement can be used to jump to the next iteration of the

loop.

continue

iters = 1 ; x = 1 while iters < 5:

iters += 1 if iters == 2:

continue

x += 1 print( “Incremented x.” )

print( f”Iterations: {iters}. x: {x}.” )

● The loop will continue until iters = 5. ● On the second iteration, continue will cause the next two statements to be

skipped (x += 1 and print( “Incremented x.” ) ).

● When the loop terminates, x will hold the value 4, and the output

“Iterations: 5. x: 4.” will be printed.

pass

Sometimes, we will want an indented block of code to do nothing (perhaps as a test, or a placeholder which we plan to fill in later).

However, Python will throw an IndentationError if we have nothing in the indented block:

if x == 2:

# TODO: Complete this later! print( “Done.” )

Instead, we can place a pass statement within the block (so no error will be thrown):

if x == 2:

pass

print( “Done.” )

Square Roots

The square root of a number a is x such that x ∗ x = a. Newton’s method: A recipe for deducing the square root of a number a ( a = 16 ):

  1. Start with a guess, x.
  2. If x ∗ x is close enough to a, stop and say x is the answer.
  3. Otherwise make a new guess y by averaging x and a / x.
  4. Using the new guess, repeat from (2) until x and y are close enough.

4.17 17.36 3.837 4.0035
4.0035 16.0277 3.997 4.000002

Algorithms

Newton’s method is a good example of a practical algorithm. To code an algorithm such as this, we need to model:

  1. A sequence of simple steps.
  2. A “flow of control” process that specifies when each step is executed.
  3. A means of determining when to stop.
