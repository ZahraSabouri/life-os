Core ideas in plain English

Time series are usually dependent
In an ordinary independent sample, one observation does not tell you about another. In a time series, neighbouring time points often carry information about each other.
A process is the generator; a series is one path
The stochastic process is the family of random variables. The observed time series is one realization/sample function from it.
Stationarity means “same after time shift”
Strict stationarity is about full distributions. Wide-sense stationarity is only about mean and covariance.
Covariance is the dependence map
R(t,s) tells how values at two time points move together. In WSS, this becomes R(t-s), so only the lag matters.

Lecture 3Definitions to write

Lecture 3 - Definitions

Continuous vs discrete time series
A time series is continuous when observations are made continuously in time. It is discrete when observations are taken only at specific times, usually equally spaced.
Deterministic vs stochastic
A deterministic time series can be predicted exactly. A stochastic time series has future values only partly determined by past values, so exact prediction is impossible.
Stochastic process
A stochastic process is a family of time-indexed random variables x_t(ω), where ω belongs to a sample space (Ω,P) and t belongs to a time set T. For fixed t it is a random variable; for fixed ω it is a realization/sample function.
Full description of a process
A process is fully described by all finite-dimensional cumulative distribution functions F_{t1,...,tn}(u1,...,un)=P(x_{t1}≤u1,...,x_{tn}≤un), for all n and all time points.
n-order stationarity
A process is n-order stationary if F_{t1,...,tn}(u1,...,un)=F_{t1+s,...,tn+s}(u1,...,un) for all time points, values and shifts s. Strict stationarity means this holds for every n.
Stationary in the wide sense
A process with E x_t² < ∞ is weakly stationary in the wide sense if E x_t is constant and Cov(x_t,x_{t+h}) does not depend on t. Equivalently, R(t,s)=R(t-s).
Gaussian process
A stochastic process x_t is Gaussian if every finite linear combination ∑ c_i x_{t_i} has a Gaussian distribution. Then each vector (x_{t1},...,x_{tn}) has a multivariate normal distribution.
L3 p.8 stationarity lemmas - memorise: These are small but very exam-friendly because they turn the CDF/density definition into short written answers.
Lemma 1: higher order implies lower order
If a stochastic process is stationary at a higher order, then it is stationary at any lower order. Example: second-order stationarity of the joint distribution implies first-order stationarity of the marginal distributions.
Lemma 2: density version of n-order stationarity
If the joint density exists and satisfies p_{t1,...,tn}(u1,...,un)=p_{t1+s,...,tn+s}(u1,...,un) for all time points, values and shifts s, then the process is n-order stationary.

Exam wording memory box

Strict vs wide: strict stationarity is distributional invariance under time shift; wide-sense stationarity only requires a constant mean and covariance depending only on lag.
Common trap: wide-sense stationarity does not automatically imply strict stationarity in general. The lecture proves the one-way result: strict stationarity plus finite second moments implies wide-sense stationarity.

Lecture 3Formula Cards

Lecture 3 - Formula Cards

Finite-dimensional CDF
F_{t1,...,tn}(u1,...,un) := P(x_{t1}≤u1, ..., x_{tn}≤un)
Symbols: t_i are time points; u_i are thresholds; x_{ti} are process values.
Use when: When asked how a stochastic process is fully described.
Trap: Do not describe only the one-dimensional distribution; the dependence is in joint distributions.
Mean function
m(t)=E x_t = ∫_{-∞}^{∞} z p_t(z) dz
Symbols: p_t is the one-dimensional density at time t.
Use when: When asked for central value/expected value at time t.
Trap: Do not write a sample average unless the question asks for an estimator.
Variance function
σ²(t)=Var(x_t)=E(x_t-m(t))²
Symbols: m(t) is the mean at time t.
Use when: When asked for dispersion around the mean.
Trap: Keep t in σ²(t) unless stationarity makes it constant.
Covariance/autocovariance
R(t,s)=Cov(x_t,x_s)=E[(x_t-m(t))(x_s-m(s))]=E[x_t x_s]-m(t)m(s)
Symbols: t and s are two time points.
Use when: When asked how two process values move together.
Trap: For independent values, covariance is 0; for dependent values, do not assume 0.
Correlation/autocorrelation
ρ(t,s)=R(t,s)/sqrt(σ²(t)σ²(s)), -1≤ρ(t,s)≤1
Symbols: Normalised covariance.
Use when: When comparing linear dependence on a scale from -1 to 1.
Trap: Correlation is undefined if a variance is 0.
Wide-sense stationarity
E x_t=m_0, Cov(x_t,x_s)=R(t-s)
Symbols: m_0 is constant; covariance depends only on lag.
Use when: When checking weak/WSS stationarity.
Trap: Do not require full distribution invariance; that is strict stationarity.
Gaussian one-dimensional density
p_t(z)=1/sqrt(2πR(t,t)) exp(-(z-m(t))²/(2R(t,t)))
Symbols: m(t)=E x_t; R(t,t)=Var(x_t).
Use when: For Gaussian process marginal density.
Trap: R(t,t) must be a variance, so it must be positive for a non-degenerate density.
Gaussian two-dimensional density
p_{t1,t2}(z1,z2)=1/sqrt((2π)² detΣ) exp(-1/2 vᵀΣ⁻¹v)
Symbols: v=(z1-m(t1), z2-m(t2))ᵀ; Σ has entries R(ti,tj).
Use when: For bivariate Gaussian process questions.
Trap: Do not put only variances in Σ; off-diagonal covariance matters.

Lecture 3Proof Skeletons

Lecture 3 - Proof Skeletons

Proof 1: Strict stationarity + E x_t² < ∞ implies wide-sense stationarity
What is being proved: if a process is strictly stationary and has finite second moments, then its mean is constant and covariance depends only on time difference.
Key steps:
1. Strict stationarity gives F_t(z)=F_{t0}(z), and hence the one-dimensional density is the same after a shift.
2. Therefore m(t)=∫z p_t(z)dz is the same for all t.
3. Strict stationarity also gives shift-invariance of the two-dimensional density p_{t1,t2}.
4. Insert that density into the covariance integral.
5. Choose the shift s=-t2, so the covariance becomes a function of t1-t2 only.
Conclusion: the process is stationary in the wide sense.
Proof 2: Basic properties of R(t) in WSS
What is being proved: R(0)=Var(x_t), ρ(0)=1, |R(t)|≤R(0), |ρ(t)|≤1, and R(-t)=R(t).
Key steps:
1. R(0)=Cov(x_t,x_t)=Var(x_t).
2. ρ(0)=R(0)/sqrt(R(0)R(0))=1 if R(0)>0.
3. Use |Cov(X,Y)|≤sqrt(Var X)sqrt(Var Y). In WSS, both variances equal R(0).
4. Symmetry: R(-t)=Cov(x_{z-t},x_z)=Cov(x_z,x_{z-t})=R(t).
Conclusion: these properties are quick checks for a proposed covariance/correlation function.
Source: ma3508_lecture3.pdf, p.11-p.13

Common proof mistakes

  • For strict ⇒ wide, forgetting the finite second moment condition.
  • Writing R(t,s)=R(t+s) instead of R(t-s).
  • Using independence when the lecture only assumes stationarity.
  • For symmetry, confusing R(-t)=R(t) with ρ(t)=R(t).
Lecture 3Repeated past-paper template

Random-Phase Sinusoid WSS Template

Why this matters: several past papers ask you to show that a random sinusoid/cosine with a uniform random phase is stationary in the wide sense and to find its covariance. This is a direct use of the L3 WSS definition.

Template A: x_t = ξ sin(λt+η)

Setup: x_t=ξ sin(λt+η), where Eξ=0, Var(ξ)=1, η~Uniform[-π,π], η is independent of ξ, and t is discrete.
Step 1 - mean:
E(x_t)=E[ξ sin(λt+η)] = E(ξ) E[sin(λt+η)] = 0.
So the mean is constant.
Step 2 - covariance:
Since E(ξ)=0 and Var(ξ)=1, we have E(ξ²)=Var(ξ)+(Eξ)²=1. R(t,s)=Cov(x_t,x_s)=E(x_t x_s) =E(ξ²) E[sin(λt+η) sin(λs+η)] =E[sin(λt+η) sin(λs+η)].
Step 3 - trig identity:
sin A sin B = 1/2 [cos(A-B)-cos(A+B)].
Use A=λt+η and B=λs+η.
Step 4 - uniform phase kills the fast term:
E_η[cos(A+B)] = E_η[cos(λ(t+s)+2η)] = 0.
Therefore only cos(A-B)=cos(λ(t-s)) remains.
Conclusion:
R(t,s)=1/2 cos(λ(t-s)).
The mean is constant and the covariance depends only on t-s, so the process is stationary in the wide sense.

Cosine and shifted-cosine versions

Cosine version: for x_t=ξ cos(λt+η), the same argument with cos A cos B gives R(t,s)=1/2 cos(λ(t-s)).
Shifted version: for x_t=1+ξ cos(λt±η), the mean is 1 and the covariance is still 1/2 cos(λ(t-s)). The constant 1 changes the mean, not the covariance.
Cos² version: for x_t=ξ cos²(At+ω), use cos²u=(1+cos2u)/2. This result assumes E(ξ)=0 and E(ξ²)=1. The mean is 0 and the covariance is 1/4 + 1/8 cos(2A(t-s)), so it also depends only on the lag.
Common trap: do not stop after showing the mean is constant. WSS requires both constant mean and covariance depending only on the lag.

Common mistakes

  • Calling any process with constant mean “stationary” without checking covariance.
  • Confusing a realization with the process itself.
  • Writing covariance as a single number when the question asks for a function of t and s.
  • For independent processes, forgetting to say covariance is 0 for different time points.
  • Thinking same one-dimensional distribution means same process; it does not.

Core ideas in plain English

White noise is independent random shock
It has the same distribution over time, and different times have zero covariance.
Random walk accumulates shocks
Each value equals the previous value plus a new white-noise shock, so variance grows with time.
Wiener process is continuous-time random walk-like motion
It starts at zero, has normal increments and independent increments.
Poisson process counts events
It jumps by one, counts occurrences, and the distribution of increments depends on interval length.
Moving average smooths or filters
It forms y_t from a finite weighted sum of nearby x-values.
Not every function can be a covariance
A valid stationary covariance must be positive semidefinite.

Lecture 4Definitions

Lecture 4 - Definitions I May Need to Write

White noise process
A process ε_t, t∈Z, is white noise if ...,ε_{t-1},ε_t,ε_{t+1},... are iid random variables with Eε_t=m and Var(ε_t)=σ². Gaussian white noise means ε_t has a normal distribution.
Random walk
x_1=ε_1 and x_t=ε_1+...+ε_t for t≥2, where ε_t is white noise with mean 0 and variance σ². Equivalently, x_t=x_{t-1}+ε_t.
Brownian motion / Wiener process
W_t, t∈[0,∞), has continuous realizations, W_0=0, normal increments W_s-W_t~N(0,s-t), and independent increments on disjoint intervals.
Brownian bridge
A Brownian bridge on [0,1] is Brownian motion pinned to return to 0 at time 1. A safe exam representation is B_t=W_t-tW_1. It satisfies B_0=0, B_1=0, E(B_t)=0, and Cov(B_t,B_s)=t(1-s), 0≤t≤s≤1.
Poisson process
P_t starts at P_0=0, P_t has Poisson distribution P(λt), has independent increments, stationary increments, and no simultaneous jumps for sufficiently small intervals.
Moving average process
y_t=∑_{i=1}^n c_i x_{t+1-i}. If c_i≥0 and ∑c_i=1, then y_t is a smoothing of x_t; a popular choice is c_i=1/n.
Short/long memory
A stationary process has short memory if ∑_{k=1}^∞ R(k) converges; it has long memory if the series diverges.
Spectral density
For a discrete stationary process with covariance R(k), f(λ)=1/(2π)∑_{k=-∞}^{∞}R(k)cos(kλ) is called the spectral density or spectrum.
Brownian bridge trap: Do not write that it is just ordinary Brownian motion. The key idea is ordinary Brownian motion conditioned/pinned to hit 0 at time 1, captured by B_t=W_t-tW_1.

Lecture 4Formula Cards

Lecture 4 - Formula Cards

White noise covariance
Cov(ε_t,ε_s)=σ² if t=s; 0 if t≠s
Symbols: σ² is variance of each iid shock.
Use when: When checking/using white noise.
Trap: Zero covariance here comes from independence and same distribution.
Random walk definition
x_t=ε_1+...+ε_t = x_{t-1}+ε_t
Symbols: ε_t is zero-mean white noise with variance σ².
Use when: When a process accumulates shocks over time.
Trap: A random walk is not WSS because Var(x_t)=tσ² changes with t.
Random walk characteristics
E x_t=0; Var(x_t)=tσ²; Cov(x_t,x_s)=tσ² for t≤s; ρ(t,s)=sqrt(t/s)
Symbols: t≤s convention; if not, use min(t,s).
Use when: For derivations and quick calculations.
Trap: Do not write Cov=0; random-walk values share past shocks.
Brownian motion covariance
E W_t=0; Cov(W_t,W_s)=min(t,s)
Symbols: W_t is Brownian/Wiener process.
Use when: When asked for Brownian motion mean/covariance.
Trap: Brownian increments are independent, but W_t and W_s themselves are not independent.
Brownian bridge
B_t=W_t-tW_1; B_0=0; B_1=0; E B_t=0; Cov(B_t,B_s)=t(1-s), 0≤t≤s≤1
Symbols: B_t is pinned at t=1.
Use when: When distinguishing bridge from Brownian motion.
Trap: The covariance is not simply min(t,s); endpoint constraint changes it.
Poisson distribution in process
P_t ~ Poisson(λt)
Symbols: λ is the intensity/rate; t is time.
Use when: When describing event counts by time t.
Trap: Stationary increments depend on interval length, not start time.
Moving average process
y_t=∑_{i=1}^n c_i x_{t+1-i}
Symbols: c_i are weights; n is window/order.
Use when: When defining finite weighted smoothing/filtering.
Trap: For smoothing, require c_i≥0 and ∑c_i=1.
MA of white noise example
y_t=(ε_t+ε_{t-1}+ε_{t-2})/3; R(0)=σ²/3; R(1)=2σ²/9; R(2)=σ²/9; R(h)=0 for h≥3
Symbols: h is lag; overlap count determines covariance.
Use when: When asked to compute covariance of finite moving average of white noise.
Trap: Count only matching ε indices; cross terms vanish.
Positive semidefinite covariance
∑_{i=1}^n∑_{j=1}^n c_i c_j R(t_i-t_j) ≥ 0
Symbols: c_i are arbitrary constants; t_i are arbitrary time points.
Use when: When checking a valid stationary covariance or proving PSD.
Trap: Do not prove only for n=2; definition is for all n.
Short vs long memory
short if ∑_{k=1}^∞ R(k)<∞; long if ∑_{k=1}^∞ R(k)=∞
Symbols: R(k) is covariance at lag k.
Use when: For convergence-test questions.
Trap: Check asymptotic decay; constants do not change convergence.
Power-law memory test
R(k) behaves like C/k^α: short if α>1; long if 0<α≤1
Symbols: C is nonzero constant.
Use when: For exam-like L4 and past-paper short/long questions.
Trap: Do not confuse exponent after simplification, e.g. (1+k^3)^{2/7} gives k^{6/7}.
Spectral density and inverse
f(λ)=1/(2π)∑_{k=-∞}^{∞}R(k)cos(kλ); R(k)=∫_{-π}^{π}cos(kλ)f(λ)dλ
Symbols: λ is frequency; k is integer lag.
Use when: When translating covariance ↔ spectrum.
Trap: Remember f(λ)=f(-λ), f(λ)≥0.

Lecture 4Proof Skeletons

Lecture 4 - Proof Skeletons

Proof 1: Random walk characteristics
What is being proved: for x_t=ε_1+...+ε_t with zero-mean white noise, E x_t=0, Var(x_t)=tσ², Cov(x_t,x_s)=tσ² for t≤s and ρ(t,s)=sqrt(t/s).
Key steps:
1. E x_t = E(ε_1+...+ε_t)=0.
2. Cov(x_t,x_s)=E[(ε_1+...+ε_t)(ε_1+...+ε_s)] for t≤s.
3. Cross terms vanish because different white-noise terms are uncorrelated/independent.
4. Only ε_1²,...,ε_t² remain, so covariance is tσ².
5. Divide by sqrt(tσ² sσ²) to get correlation sqrt(t/s).
Conclusion: random walk variance grows with time, so it is not wide-sense stationary.
Proof 2: Moving average of white noise covariance
What is being proved: for y_t=(ε_t+ε_{t-1}+ε_{t-2})/3, the covariance drops as overlap decreases.
Key steps:
1. E y_t=0 because each shock has zero mean.
2. For R(0), three matching terms remain: σ²+σ²+σ² divided by 9 = σ²/3.
3. For R(1), two overlapping shocks remain: ε_t and ε_{t-1}, giving 2σ²/9.
4. For R(2), one overlapping shock remains: σ²/9.
5. For lag 3 or more, no overlapping terms remain, so covariance is 0.
Conclusion: finite moving average processes have finite dependence range.
Proof 3: Covariance function is positive semidefinite
What is being proved: a stationary covariance function R must satisfy ∑∑c_i c_j R(t_i-t_j)≥0.
Key steps:
1. Define ξ=∑ c_i x_{t_i}.
2. Since variance is nonnegative, Var(ξ)≥0.
3. Expand Var(ξ)=Cov(∑c_i x_{t_i},∑c_j x_{t_j}).
4. By bilinearity, this equals ∑∑c_i c_j Cov(x_{t_i},x_{t_j}).
5. Since the process is stationary, Cov(x_{t_i},x_{t_j})=R(t_i-t_j).
Conclusion: the required double sum is nonnegative.
Source: ma3508_lecture4.pdf, p.5-p.6, p.13-p.16

  { CovMtp[i,j] = 1.6*exp(-0.7*abs(tp[i]-tp[j]))
  }}

Lecture 4Mistakes and self-test

Lecture 4 - Common Mistakes and Mini Self-test

Common mistakes

  • Random walk: saying it is stationary because the shocks are stationary. The accumulated process has Var(x_t)=tσ².
  • Brownian motion: saying W_t and W_s are independent. The increments are independent on disjoint intervals, not the levels themselves.
  • Brownian bridge: forgetting the endpoint condition B_1=0.
  • Poisson process: confusing independent increments with stationary increments. Independent means disjoint intervals do not affect each other; stationary means distribution depends only on interval length.
  • Moving average covariance: counting all cross-products instead of only overlapping identical white-noise terms.
  • PSD proof: proving for one pair of times only; PSD is for all n, all c_i, all t_i.
  • Short/long memory: using R(t) as t→0 instead of the tail k→∞.
  • Spectrum: forgetting the backward transform from f(λ) to R(k).
Source: ma3508_lecture4.pdf, p.4-p.18; solution-exam-like-exercises-L4.pdf, p.1

Mini self-test

  1. Write the covariance function of white noise.
  2. For x_t=ε_1+...+ε_t, why is Cov(x_t,x_s)=tσ² when t≤s?
  3. State the Wiener process definition in four bullets.
  4. What is the formula for a Brownian bridge in terms of W_t and W_1?
  5. What does “stationary increments” mean for a Poisson process?
  6. Classify R(k)=1/(1+k²) as short- or long-range.
  7. State the positive semidefinite condition for a covariance function.
  8. Write the spectral density formula and the backward transform.
Fast answers: 1) σ² at same time, 0 otherwise. 2) shared shocks only. 3) W0=0, continuous realizations, normal increments, independent increments. 4) B_t=W_t-tW_1. 5) increment distribution depends only on interval length. 6) short-range. 7) ∑∑c_i c_j R(t_i-t_j)≥0. 8) f(λ)=1/(2π)∑R(k)cos(kλ), R(k)=∫cos(kλ)f(λ)dλ.
