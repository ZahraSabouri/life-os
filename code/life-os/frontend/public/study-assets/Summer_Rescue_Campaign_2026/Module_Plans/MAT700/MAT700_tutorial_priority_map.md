# MAT700 Tutorial Priority Map

Core principle: tutorial problems and solutions are the centre of revision. Lecture slides support the tutorials; they do not replace problem practice.

## High-yield areas

- Birthday/expected count and Bonferroni-style reasoning
- IDF and TF-IDF
- document-term matrix and vector-space model
- graph basics: sum of degrees, adjacency matrix, powers of adjacency matrix
- Jaccard similarity: sets and bags
- distance axioms and proofs: L-infinity, edit distance, Jaccard distance
- kNN and distances
- Naive Bayes
- PageRank/link analysis
- clustering and k-means
- softmax and cross-entropy
- learning framework
- precision/recall/F-measure
- halving and weighted majority/expert algorithms
- AdaBoost-style reasoning if included in materials

## Study method

For each topic:

1. Targeted lecture skim
2. Formula/procedure sheet
3. Tutorial attempt
4. Solution check
5. Immediate correction
6. Error log
7. 2–3 flashcards or recall questions
