Lectures 1–2 Core Concepts

L1: data mining, learning types, Bonferroni, birthday

Definitions you can write

  • Data mining: finding useful patterns, structure, predictions, or explanations in large datasets.
  • Supervised learning: training data include labels/targets y; goal is to predict y for new x. Example: spam/not spam, digit classification.
  • Unsupervised learning: no target labels; goal is to find structure. Example: clustering customers/documents.
  • Semi-supervised learning: small labelled set plus large unlabelled set; use both to learn.
  • Classification: predict finite/discrete class label. Regression/numerical prediction: predict a numerical value.

Bonferroni principle answer

If the expected number of random occurrences of a pattern is large, then many observed occurrences may be meaningless coincidences. In data mining, when searching huge spaces, even rare random events appear often. Use it to warn against over-interpreting patterns found after many trials.

Exam sentence: If the number of opportunities is n and probability of a random success is p, the expected number of false/random hits is np. If np is not small, the discovered pattern may not be significant.

Bonferroni / expected random hits
Use for “expected bogus/random matches”, not exact probability.
Birthday m-tuples
Pairs: m=2. Triples: m=3. K people, N boxes/days.

Birthday expected-count method

  1. Choose the group: pairs/triples/m-tuples: C(K,m).
  2. For a fixed group of m people, first birthday is arbitrary.
  3. Remaining m−1 people must match it: probability = 1/Nm−1.
  4. Expected count = number of groups × probability.

Pairs in 30 students: C(30,2)/365 = 435/365 ≈ 1.192. Triples: C(K,3)/365².

L2: standard formulation and mathematical framework

Standard data form

  • Universe U: the huge set of possible objects.
  • Object/instance/record: one row, one data item.
  • Attributes/features: measured variables/columns.
  • Dataset: table of instances × attributes.
  • Labelled data: one attribute is target y. Unlabelled: no target attribute.

Instance-based vs model-based

  • Instance-based: keep training examples; when new x arrives, compare to stored examples. kNN is the main example.
  • Model-based: learn a function/model f:X→Y from data; after training, predict using the model instead of comparing with all data.
  • Why model-based? faster prediction and no need to carry the whole dataset.
  • Why instance-based? simple and flexible; can work well with enough relevant data.
Learning risk / empirical risk
ERM chooses h in H minimizing empirical risk.
Softmax
Converts scores/logits to probabilities summing to 1.
Cross entropy
One-hot version: −log(probability assigned to true class).

Mathematical framework answer

We assume training examples (xᵢ,yᵢ) are sampled from an underlying distribution. We choose a hypothesis space H of possible models, choose a loss L measuring prediction error, define expected risk R(h), then choose a model with small empirical risk on the training data. The key idea is to replace the unknown true risk by the observed average training loss.

Lecture 2 High-Yield Calculations

L2: TF-IDF and document-term matrix

TF-IDF
Use column maximum for TF, not total words. Use log base 2 unless told otherwise.
TF-IDF bound
Past papers ask: show less than 9/11 by bounding log₂(N).

Definition answer

Document-term matrix: rows are terms/words, columns are documents, and entry (i,j) is usually the frequency/count or TF-IDF weight of term i in document j. It represents documents as vectors so similarity/classification algorithms can be applied.

TF-IDF idea: a word is important in a document if it occurs often in that document but is not common across the whole corpus.

TF-IDF workflow

  1. Start with raw count matrix fᵢⱼ.
  2. Remove all-zero rows/columns if needed.
  3. For each document column j, find max word count maxₖ fₖⱼ.
  4. Compute TFᵢⱼ = fᵢⱼ / column max.
  5. For each term i, count nᵢ = number of documents containing it.
  6. IDFᵢ = log₂(N/nᵢ).
  7. Multiply row i by IDFᵢ to get TF-IDF.

Typical bound proof

Because fᵢⱼ ≤ maxₖ fₖⱼ, we have TFᵢⱼ ≤ 1. Since nᵢ ≥ 1 for any word appearing in a document, N/nᵢ ≤ N, so IDFᵢ ≤ log₂N. Therefore TF-IDFᵢⱼ ≤ log₂N. For N=500, log₂500 < 9 because 500 < 512 = 2⁹. For N=1500, log₂1500 < 11 because 1500 < 2048 = 2¹¹.

L2: graph basics

Degree-sum theorem
Each undirected edge contributes exactly 2 to the total degree count.
Walk-count fact
Prove by induction using matrix multiplication.

Adjacency matrix

For an unweighted graph, Aᵢⱼ = 1 if there is an edge from i to j, otherwise 0. For undirected graphs, A is symmetric. For weighted graphs, use the edge weight instead of 1.

Walk-count proof skeleton

Base case r=1: Aᵢⱼ counts one-step walks. Inductive step: (Aʳ⁺¹)ᵢⱼ = Σₖ(Aʳ)ᵢₖAₖⱼ. This sums all length-r walks from i to k followed by one edge k→j, so it counts length r+1 walks.

Lecture 3 Similarity and Near-Duplicates

L3: similar items, Jaccard, shingling, minhashing

Jaccard similarity / distance
Sets: ignore repeated elements.
Jaccard for bags
Bags: multiplicities matter. Do not use ordinary union size.
Minhash key property
Minhash converts Jaccard similarity into matching probability.

Similar-items pipeline

  1. Represent a document/object as a set or bag of features.
  2. For text, create k-shingles: consecutive substrings/words of length k.
  3. Similar documents should share many shingles.
  4. Use Jaccard similarity to measure overlap.
  5. Use minhashing to approximate Jaccard quickly for many documents.
  6. Candidate pairs can then be checked with exact Jaccard.

Shingling answer

Shingling transforms a document into the set of all overlapping k-length substrings or word sequences. Small k is too insensitive because many unrelated documents share short shingles; large k is too strict because small edits destroy many matches. k is a hyperparameter.

Jaccard bags ≤ 1/2 proof idea

For bags as used in the course, the “bag union” counts combined multiplicities while the “bag intersection” counts minimum multiplicities. For each element, min(a,b) ≤ (a+b)/2. Summing over x gives intersection count ≤ half of total bag count. Therefore Jaccard similarity of bags is ≤ 1/2 under that bag definition. In the min/max version, remember to use Σmin / Σmax when computing.

Jaccard distance proof memory

Non-negativity and symmetry follow from 0≤J≤1 and symmetric intersection/union. Identity: d=0 means J=1, so the sets are equal. Triangle inequality is the hard part: use minhash interpretation. d(S,T)=Pr[h(S)≠h(T)]. If h(S)≠h(U), then either h(S)≠h(T) or h(T)≠h(U). So by union bound, d(S,U)≤d(S,T)+d(T,U).

Trap: Set Jaccard ignores duplicates. Bag Jaccard uses multiplicity. Do not mix them.

Lecture 4 Distances and kNN

L4: distance measures

Metric axioms
For a proof question, check all four.
Common distances
L∞ is Chebyshev/max distance.

L∞ proof skeleton

  • Non-negative: max of absolute values is ≥0.
  • Identity: maxᵢ|xᵢ−yᵢ|=0 means every coordinate difference is 0, so x=y.
  • Symmetry: |xᵢ−yᵢ|=|yᵢ−xᵢ|.
  • Triangle: for every i, |xᵢ−zᵢ|≤|xᵢ−yᵢ|+|yᵢ−zᵢ|≤d∞(x,y)+d∞(y,z). Taking max over i gives d∞(x,z)≤d∞(x,y)+d∞(y,z).

Edit distance proof skeleton

  • Non-negative: number/cost of edits cannot be negative.
  • Identity: zero edits needed iff strings are identical.
  • Symmetry: each insertion has a reverse deletion; substitution reverses to substitution.
  • Triangle: an optimal edit script from x to y followed by one from y to z is a valid script from x to z. The shortest script from x to z cannot be longer than that concatenated script.

L4: kNN and weighted kNN

Weighted kNN vote
Pick the class with largest total weight. Close neighbours count more.

kNN answer

k-nearest neighbour classification is an instance-based method. For a new point x, compute distances from x to training points, select the k closest, and assign the majority class. In weighted kNN, closer neighbours get larger weight, commonly 1/d or 1/d², and the predicted class is the one with largest total neighbour weight.

kNN calculation checklist

  1. Compute distance from test point to each labelled point.
  2. Sort by distance.
  3. For 2-NN/3-NN etc., select nearest labelled neighbours. If test point itself is in the table with unknown label, do not count it as labelled.
  4. Majority vote: count labels.
  5. Weighted vote: add 1/dᵖ by class.

Choosing k

k is a hyperparameter. Small k can be noisy/overfit; large k can oversmooth and ignore local structure. In practice, try several k values and evaluate on validation/test data.

Lecture 4 Evaluation and Naive Bayes

L4: model evaluation

Precision, recall, F1
Precision = “of predicted positive, how many correct?” Recall = “of actual positive, how many found?”

Confusion matrix

Pred +Pred −
Actual +TPFN
Actual −FPTN

Precision punishes false positives. Recall punishes false negatives.

F1 ≤ (P+R)/2 proof

Need prove 2PR/(P+R) ≤ (P+R)/2. Multiply by 2(P+R)>0: 4PR ≤ (P+R)². But (P+R)²−4PR = (P−R)² ≥ 0. Therefore F1 ≤ arithmetic mean of precision and recall.

L4: Naive Bayes

Naive Bayes classifier
Denominator P(x) is same for all classes, so compare proportional scores.

Description answer

Naive Bayes is a probabilistic supervised classifier. For each possible class C, it computes a posterior score using Bayes’ rule. The “naive” assumption is class-conditional independence: once the class is known, the attributes are treated as independent. Therefore the likelihood factors as a product of one-attribute probabilities.

Calculation workflow

  1. List classes, e.g. Play=Yes/No.
  2. Compute prior P(C)=count(C)/total.
  3. For each class, compute conditional probabilities P(attribute value | C).
  4. Multiply: score(C)=P(C)∏P(xⱼ|C).
  5. Compare scores. Normalise only if asked for actual posterior probabilities.
Trap: If one conditional count is zero, the whole score becomes zero unless smoothing is specified. If the exam data uses no smoothing, just follow the table.

Lecture 5 PageRank

L5: PageRank

Transition matrix
Column j tells where a surfer on page j goes next.
PageRank
M is column-stochastic: column j distributes page j’s rank to its out-links.

PageRank description answer

PageRank assigns a score to each web page representing the long-run probability that a random surfer is on that page. The surfer follows outgoing links with probability β and teleports uniformly to any page with probability 1−β. The PageRank vector is the stationary distribution satisfying r=βMr+(1−β)1/n.

Calculation workflow

  1. Draw directed graph and count out-links of each page.
  2. Build M column by column: if page j links to i, put 1/out(j) in row i, column j.
  3. Write r = βMr + (1−β)/n · 1.
  4. Add normalisation Σrᵢ=1 if solving equations.
  5. Solve small linear system or iterate if instructed.

Spider trap / dead end

A spider trap is a group of pages with outgoing links only inside the group, so rank can get stuck there. Teleportation prevents this by giving every page a baseline chance of receiving rank. A dead end has no out-links; it must be handled by redistributing its rank, commonly uniformly.

Only out-links equal PageRank idea

If two pages have no incoming links from other pages, their rank comes only from the teleportation term. Since teleportation is uniform, their PageRank values are equal. State clearly that this depends on interpreting “only out-links” as no in-links.

PageRank exam traps

  • Columns of M should sum to 1, not rows, in this lecture convention.
  • Column j is the source page j. Row i is the destination page i.
  • Do not forget the damping/teleportation term.
  • If β=0.8 and n=4, teleportation term is (0.2/4)=0.05 to each page.

Lecture 6 Clustering and k-means

L6: clustering, hierarchical clustering, k-means

Hierarchical linkage
Average linkage averages all pairwise distances; centroid linkage uses centroid distance.
k-means objective
Alternate assignment and centroid update until stable.

Clustering definition

Clustering is unsupervised learning: we group unlabelled objects so that objects in the same cluster are similar or close, and objects in different clusters are dissimilar or far apart. It depends strongly on the chosen distance/similarity and scale.

Hierarchical clustering answer

Agglomerative hierarchical clustering starts with each point as its own cluster. At each step, merge the two closest clusters according to a linkage rule. Repeat until the desired number of clusters remains. Single linkage can create chains; complete linkage tends to create tighter clusters; average linkage is a compromise.

k-means algorithm

  1. Choose k initial centroids, often randomly or from selected data points.
  2. Assignment step: assign each point to the nearest centroid.
  3. Update step: replace each centroid by the mean of its assigned points.
  4. Repeat until assignments stop changing or objective stops decreasing.

Convergence proof skeleton

The assignment step cannot increase the objective because each point is assigned to its nearest centroid. The update step cannot increase the objective because the mean minimises sum of squared distances within a cluster. There are finitely many possible assignments, so the algorithm eventually stops at a local optimum.

Trap: k-means may converge to different local optima for different initial centroids. It does not guarantee the global best clustering.

Lecture 7 Meta-algorithms

L7: meta-algorithms, halving, weighted majority, AdaBoost

Halving mistake bound
On each mistake at least half the remaining experts are removed; one perfect expert survives.
Weighted Majority update
Wrong experts are penalised multiplicatively, not deleted.
AdaBoost learner weight
Smaller error ε gives larger α; misclassified training points gain influence.

Meta-algorithm answer

A meta-algorithm is an algorithmic strategy that combines or controls other algorithms/experts/weak learners to improve performance. Instead of relying on one predictor, it uses a collection and updates trust/weights according to mistakes.

Halving algorithm

Maintain a version space of experts/hypotheses still consistent with observed data. At each round, predict by majority vote of current experts. After seeing the true label, remove all experts that were wrong. It assumes at least one perfect/consistent expert exists.

Halving proof

If the algorithm makes a mistake, the majority of current experts were wrong, so at least half are removed. After M mistakes, at most n/2ᴹ experts remain. Since one consistent expert remains, n/2ᴹ ≥ 1. Therefore 2ᴹ ≤ n and M ≤ log₂n.

Weighted majority

Instead of deleting wrong experts, keep weights. Predict by weighted vote. After the true label is revealed, multiply wrong experts’ weights by β, where 0<β<1. This is more flexible than halving because experts can recover from occasional mistakes.

AdaBoost memory

AdaBoost repeatedly trains weak learners on reweighted data. Misclassified examples get more weight, so the next weak learner focuses on them. Learners with smaller error get larger α. The final classifier is a weighted vote of weak learners.

One-Page Proof Bank

Proofs you should be able to write from memory

1) Degree sum theorem

Each undirected edge has exactly two endpoints. When summing degrees over all vertices, every edge is counted once at each endpoint. Therefore the total degree sum is 2|E|.

2) F1 bound

F1 = 2PR/(P+R). Need show ≤(P+R)/2. Equivalent to 4PR≤(P+R)². Difference is (P−R)²≥0.

3) Halving mistakes

Every mistake removes at least half the current experts; one perfect expert survives. After M mistakes at least 1 remains, so n/2ᴹ≥1, hence M≤log₂n.

4) k-means convergence

Assignment to nearest centroid does not increase squared-distance objective. Updating each centroid to the mean minimises squared error inside that cluster. Objective decreases or stays same; finitely many assignments; stop at local optimum.

5) Edit distance metric

Edit costs are nonnegative; zero cost iff same string; symmetry by reversing edit operations; triangle by concatenating an optimal x→y edit script with an optimal y→z script to get a valid x→z script.

6) L∞ metric

Use absolute value properties coordinatewise. For triangle, |xᵢ−zᵢ|≤|xᵢ−yᵢ|+|yᵢ−zᵢ|≤d∞(x,y)+d∞(y,z), then take max over i.

7) TF-IDF bound

TF≤1. IDF=log₂(N/nᵢ)≤log₂N. Therefore TF-IDF≤log₂N. Compare N to powers of 2.

8) Jaccard distance triangle

Use minhash: d(S,T)=Pr[h(S)≠h(T)]. If h(S)≠h(U), then h(S)≠h(T) or h(T)≠h(U). Thus event C⊆A∪B, so Pr(C)≤Pr(A)+Pr(B).

SVM terms from 2023 paper

  • Linearly separable: there exists a hyperplane separating classes without error.
  • Margin: distance from separating hyperplane to closest training points; SVM maximises it.
  • Support vectors: closest points that determine the decision boundary.
  • Multiclass to binary: one-vs-rest or one-vs-one binary classifiers.
SVM plane margin
For x₁−2x₂+12x₃−33=0, ||w||=√149, margin=1/√149 if using this convention.

Graph Laplacian / harmonic function

Unnormalised graph Laplacian
D is weighted degree diagonal matrix; W is weighted adjacency matrix.

A harmonic function on a graph has value at an unlabelled node equal to a weighted average of neighbouring values. In semi-supervised graph learning, labelled nodes are fixed and labels propagate through the graph.

Final common traps

  • Expected count ≠ probability. Birthday/Bonferroni questions are expected values unless explicitly asking probability.
  • TF uses column max, not total document length.
  • IDF uses log₂ unless stated otherwise.
  • Jaccard distance = 1 − similarity.
  • Bags are not sets.
  • PageRank M is column-stochastic.
  • Weighted kNN: close points can beat the majority.
  • Naive Bayes: compare proportional scores, denominator cancels.
  • k-means: convergence is local, not global.
  • Halving: requires one consistent expert.
