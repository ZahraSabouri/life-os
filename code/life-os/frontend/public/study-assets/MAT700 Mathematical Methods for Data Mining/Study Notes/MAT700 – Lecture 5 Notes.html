One-sentence memory version

PageRank ranks pages by the long-run probability that a random surfer visits them. Links from important pages pass more importance than links from unimportant pages. The real exam skill is: build M, apply the damped equation, and explain dead ends/spider traps clearly.
09.05.2026MAT700 Lecture 5 - intuition

Why PageRank Exists

A. Search before PageRank

Early search engines could be fooled by term spam: a page could repeat a query word many times and appear important even if it was useless. Google's PageRank idea was to use link structure: not just what a page says about itself, but how other pages link to it. The content of a page can still matter, but PageRank gives a query-independent importance score that can be computed in advance.

B. Random surfer interpretation

Imagine a surfer who starts on a random page, follows one outgoing link at random, and keeps doing this for a long time. A page has high PageRank if the surfer is likely to be found there in the long run. This captures two ideas at once: many incoming links help, and incoming links from already important pages help even more.
Exam phrase: PageRank is a function assigning a real number to each page; larger value means the page is treated as more important.
Do not write: “PageRank is just the number of in-links.” It is recursive: a link from an important page contributes more than a link from an unimportant page.

Dead Ends and the Stochastic-Matrix Fix

H. What is a dead end?

A dead end is a page with no outlinks. If a surfer reaches it, the ordinary link-following process has nowhere to go. In matrix terms, the column for that page sums to 0, not 1, so M becomes substochastic.

09.05.2026MAT700 Lecture 5 - spider traps

Spider Traps and Taxation / Damping

J. What is a spider trap?

A spider trap is a set of nodes with outlinks but no arcs leaving the set. Once the surfer enters the set, ordinary PageRank keeps them there forever. Then all or too much PageRank may concentrate inside the trap.

K. Damped PageRank model

The fix is to allow teleportation: with probability 1−β the surfer jumps uniformly to any page; with probability β the surfer follows the link matrix M.
Matrix form
E is the n×n all-ones matrix.
Vector form

Iteration form
Use this for hand calculations.
Common values
If β=0.8 and n=3, teleportation contributes 1/15 to each page.

L. Why damping overcomes spider traps

A trap no longer keeps all PageRank because the surfer can teleport out with non-zero probability. The trap can still receive high PageRank, but it cannot absorb everything. This is exactly what 2025 Q3(d) asks you to explain.
Write in exam: “The model adds a uniform teleportation component, so the Markov chain can escape closed link structures and every page receives at least some baseline probability.”

09.05.2026MAT700 Lecture 5 - 2023 proof pattern

2023 Q2(b) Proof Pattern + Final Memory Page

R. Describe how to calculate PageRank

Represent the Web as a directed graph. Build the transition matrix M: each page's outlinks divide that page's probability equally. Start from a probability vector, often uniform. Iterate the PageRank update until values change very little. For the real Web, fix dead ends and use damping/taxation.

S. Prove pages with only outlinks have the same PageRank

Interpretation used here: “only outlinks” means the page has outgoing links but no incoming links. Then no other page points to it.
For such a page i, row i of M has no incoming link contributions:

Damped PageRank value
Therefore any two pages with no incoming links have the same PageRank value, because both receive only the uniform teleportation amount.
Careful: if the exam uses the ideal model without damping, then such pages get 0 instead of (1−β)/n. The equality argument is the same.

  • Dead end = no outlinks; fix the zero column with e/n.
