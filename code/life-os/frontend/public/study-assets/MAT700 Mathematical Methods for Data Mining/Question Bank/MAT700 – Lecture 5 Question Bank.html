09.05.2026MAT700 Lecture 5 answers A1-A4

Answers / Worked Solutions

Concept and definitions

A1. PageRank is a function assigning a real number to each page. The intended meaning is: the larger the value, the more important the page. In random-surfer language, PageRank is the long-run probability that a random surfer is on that page.
A2. Early search ranked pages by the terms appearing in them, so pages could fool the system by repeating terms. Link structure is harder to fake because a page becomes important by being linked to, especially by pages that are themselves important.
A3. Model the Web as a directed graph. Pages are nodes. A directed arc from page p to page q means p has at least one link to q.
A4. Column j represents the page where the surfer is currently located. Row i is a possible destination. If page j has k outgoing links and one is to page i, then the entry is 1/k; otherwise it is 0.
transition rule

Fixed point, convergence, scale

A9. At the limiting distribution, one more random-surfer step no longer changes the vector. Therefore the limiting PageRank vector satisfies:

A10. The Markov process approaches a limiting distribution under the strong connectedness condition: from any node, it is possible to reach any other node by following directed links.
condition
A11. Gaussian elimination is not feasible at Web scale because it is cubic in the number of equations. Real Web graphs have huge numbers of nodes, so PageRank is computed by iterative multiplication until the vector changes very little.
A12. A dead end is a page with no outlinks. Its column in the transition matrix is all zero, so the matrix is no longer stochastic and probability mass can disappear.

Dead ends, spider traps, damping

A14. A substochastic matrix has non-negative entries and column sums at most 1. If a column sum is 0, probability mass can drain away through a dead end, so the limiting vector can lose useful information.
A15. A spider trap is a set of pages with outlinks inside the set but no links leaving the set. Difference: a dead end has no outlinks; a spider trap has outlinks, but they do not escape.
A16. In a one-node spider trap such as C→C, once the surfer reaches C, they cannot leave under the ordinary link-following model. Iteration therefore places all PageRank inside the trap.
A17. The damped PageRank equation is:
matrix form
vector update form
Here M is the stochastic transition matrix after dead-end repair, β is the damping factor, e is the all-ones vector, n is the number of pages, and (1−β)e/n is the uniform teleportation/taxation part.
A18. Damping gives the surfer probability β of following a link and probability 1−β of teleporting uniformly to any page. Therefore even if the surfer enters a spider trap, there is always a non-zero probability of escaping.
A19. If β=0, all link structure is ignored and every page receives uniform rank. If β=1, there is no teleportation, so spider traps can absorb rank. Practical PageRank uses β strictly between 0 and 1; the lecture notes mention β=0.85 for Google.
practical range

Exam explanation patterns

A25. Spider traps are groups of nodes with no dead ends but no arcs out. They can intentionally or unintentionally trap all PageRank. The damped model overcomes this by allowing a teleport to any page with probability 1−β.
damped model
A26. To calculate Google PageRank: model the Web as a directed graph; build the column-stochastic transition matrix; repair dead ends by replacing zero columns with uniform columns; apply damping; start from a uniform vector; iterate until convergence.

09.05.2026MAT700 Lecture 5 answers A29-A35

Answers / Worked Solutions cont.

Checks and conceptual extensions

A29. Two quick checks: all PageRank values must be non-negative, and the entries should sum to 1. In a β=0.8 three-page calculation, the teleportation part should be 1/15 in every component.
A30. A link from an important page contributes more because the transition distributes the current page’s PageRank through its outlinks. More incoming links help, but links from already-important pages help more.
A31. PageRank can rank any directed network, not only Web pages: papers citing papers, users following users, or players beating other players, provided the directed edge has a meaningful “endorsement” interpretation.
A32. The recording frames ranking as choosing among many possible outputs. In a search query, pages can be ordered by relevance; PageRank pre-computes a query-independent importance score for pages, then search can combine this with query matching.
ranking idea
A33. If M is stochastic, each column of βM sums to β and each column of (1−β)E/n sums to 1−β. Therefore each column of the damped matrix sums to 1.
damped matrix
A34. Damping makes the effective graph strongly connected because from every page there is a non-zero probability of jumping to every other page. This prevents permanent trapping in isolated components.
A35. Common mistakes: using row-stochastic instead of column-stochastic convention; forgetting to split probability by number of outlinks; not repairing dead ends before damping; confusing dead ends with spider traps; forgetting the constant teleportation term; not checking that the final values sum to 1.
