09.05.2026A1-A8

Answers: Distance Measures I

Answers to Q1-Q12.
A1. A distance measure is a function d(x,y) taking two points in a space and returning a real number. It must satisfy: (1) d(x,y)≥0; (2) d(x,y)=0 ⇔ x=y; (3) d(x,y)=d(y,x); (4) d(x,y)≤d(x,z)+d(z,y).
A2. max(x,y) is not a distance because max(3,3)=3≠0. |x-y| is a distance: it is the standard absolute-value distance. x+y is not a distance because d(3,3)=6≠0.
A3. Coordinate differences are 3,4,3. Therefore L₁=3+4+3=10, L₂=√(3²+4²+3²)=√34, and L∞=max(3,4,3)=4.
A4. The pairwise Hamming distances are: d(x,y)=4, d(x,z)=3, d(x,w)=3, d(y,z)=3, d(y,w)=5, and d(z,w)=2.
A5. For d∞(x,y)=maxᵢ|xᵢ-yᵢ|: non-negativity is clear from absolute values. If x=y, all differences are zero, so d∞=0; conversely, if d∞=0, then every |xᵢ-yᵢ|=0, so x=y. Symmetry follows from |xᵢ-yᵢ|=|yᵢ-xᵢ|. For triangle inequality, choose i₀ where d∞(x,y)=|xᵢ₀-yᵢ₀|. Then |xᵢ₀-yᵢ₀|≤|xᵢ₀-zᵢ₀|+|zᵢ₀-yᵢ₀|≤d∞(x,z)+d∞(z,y).
A6. Edit distance is the smallest number of insertions and deletions needed to transform one string into another. It is non-negative because it counts operations. It is zero iff the strings are already identical. It is symmetric because a sequence from x to y can be reversed by swapping insertions and deletions. Triangle inequality: a shortest path from x to z plus a shortest path from z to y gives a valid path from x to y, so the shortest possible path from x to y is no longer than that sum.
A7. abcde → acde by deleting b; acde → acfde by inserting f; acfde → acfdeg by inserting g. So distance is at most 3. It cannot be 0 or 1 because the strings differ by more than one edit. It cannot be 2 because y contains two new letters f,g and also lacks b, requiring at least two insertions and one deletion. Hence d=3.
A8. An LCS of aba and bab has length 2, for example ab or ba. Therefore d(x,y)=|x|+|y|-2|LCS|=3+3-2·2=2.
09.05.2026A9-A12

Answers: Distance Measures II

Answers to Q9-Q12.
A9. For sets, SIM(X,Y)=|X∩Y|/|X∪Y| and d_J(X,Y)=1-SIM(X,Y). Non-negativity follows because similarity is between 0 and 1. d_J(X,Y)=0 iff similarity is 1, which means the sets are equal. Symmetry follows because intersection and union are symmetric. For triangle inequality, use the minhash interpretation: SIM(X,Y)=P(hπ(X)=hπ(Y)), so d_J(X,Y)=P(hπ(X)≠hπ(Y)). If hπ(X)≠hπ(Z), then either hπ(X)≠hπ(Y) or hπ(Y)≠hπ(Z). Therefore the event for X,Z is contained in the union of the other two events, and its probability is at most the sum. Hence d_J(X,Z)≤d_J(X,Y)+d_J(Y,Z).
A10. Cosine distance treats the direction of a vector as important and ignores scaling of its length. It is useful when multiplying all coordinates by a positive constant should not change the object: for example, the same image under different brightness, or a document vector scaled by length/frequency.
A11. Numerical vectors: use L₁, L₂, or L∞, depending on whether total deviation, Euclidean geometry, or maximum coordinate difference matters. Categorical records: Hamming distance is a simple baseline because it counts different attributes. Strings: edit distance is natural because it counts insert/delete transformations. Scale-invariant vectors: cosine distance is natural because it compares direction rather than magnitude.
A12. The missing axioms are identity of indiscernibles and triangle inequality. This matters because many functions are non-negative and symmetric but still fail to be genuine distances. Example: max(x,y) is symmetric and non-negative on non-negative integers, but max(3,3)=3, so the distance from a point to itself is not zero.
Distance-proof exam pattern: Always write the four headings: non-negative, zero iff equal, symmetric, triangle inequality. Missing a heading makes the proof look incomplete even if the idea is right.
09.05.2026A13-A20

Answers: kNN

Answers to Q13-Q20.
A13. Given a new unseen instance, compute its distance to the training examples, find the k closest training instances, and assign the class that occurs most often among those neighbours. If there is a tie, a tie-breaking rule is needed.
A14. Weighted kNN still uses the k nearest neighbours, but gives closer neighbours larger votes. With wᵢ=1/d(y,zᵢ)², each class receives the sum of weights of neighbours in that class. This can be better than majority vote because one very close neighbour can outweigh several farther neighbours.
A15. For x=5.5, the nearest point is 5.75 with label +, so 1NN gives +. For 3NN, the nearest are 5.75(+), 5.0(-), and either 4.5(-) or 6.5(-). Majority is negative, so 3NN gives -.
A16. Weighted 1NN is still +. For weighted 3NN, the positive weight is 1/(0.25)²=16. The negative weights are 1/(0.5)²+1/(1.0)²=4+1=5. Since 16>5, weighted 3NN gives +.
A17. For z=(0.25,0.80), the nearest four under L∞ are instance 2 (+) at distance 0.05, instance 4 (-) at 0.25, instance 5 (-) at 0.50, and instance 6 (+) at 0.50. Positive weight is 1/0.05²+1/0.50²=400+4=404. Negative weight is 1/0.25²+1/0.50²=16+4=20. Therefore classify as +.
A18. Distances from 36: to 25 is 11 with label -; to 49 is 13 with label +; to 16 is 20 with label -; to 9 is 27 with label -; to 64 is 28 with label -. 2NN gives one negative and one positive, so it is a tie unless a tie rule is specified. 3NN gives -,+,-, so classify as -.
A19. For 2NN, negative weight is 1/11² and positive weight is 1/13². Since 1/11²>1/13², weighted 2NN gives -. For 3NN, the extra neighbour at 16 is also negative, so weighted 3NN is also -.
A20. As k increases, the kNN decision boundary usually becomes smoother. Training error can increase because the classifier no longer simply follows individual training points. A very small k, especially k=1, can overfit: training error can be zero while test error is worse.
09.05.2026A21-A27

Answers: Model Evaluation

Answers to Q21-Q27.
A21. TP: predicted positive and actually positive. FP: predicted positive but actually negative. FN: predicted negative but actually positive. TN: predicted negative and actually negative.
A22. Precision=TP/(TP+FP). Recall=TP/(TP+FN). True negative rate=TN/(TN+FP). Accuracy=(TP+TN)/(TP+TN+FP+FN). F=2·precision·recall/(precision+recall).
A23. Tutorial spam example: TP=90, FN=10, TN=700, FP=200. Precision =90/(90+200)=9/29. Recall =90/(90+10)=9/10. F-measure =2·(9/29)(9/10)/(9/29+9/10)=6/13.
A24. 2023-style spam example: TP=90, FN=10, TN=300, FP=100. Precision =90/(90+100)=9/19. Recall =90/100=9/10. F-measure =2·(9/19)(9/10)/(9/19+9/10)=18/29.
A25. Let P be precision and R be recall. Then F=2PR/(P+R). We need 2PR/(P+R)≤(P+R)/2. Since P+R>0, multiply by 2(P+R) to get 4PR≤(P+R)². This is true because (P-R)²≥0, so P²+2PR+R²≥4PR.
A26. Accuracy can be misleading when one class is rare. If only 0.5% of patients have cancer, a classifier that always predicts “no cancer” is about 99.5% accurate but completely useless for detecting cancer. Precision and recall focus on the positive class we care about.
A27. Training error is error on data used to fit the model. Generalisation error is expected error on future unseen data. Overfitting happens when a model fits noise or minor variation in the training data, giving low training error but poor future performance. An independent test set is needed because it approximates future unseen data and gives a more reliable performance estimate.
09.05.2026A28-A37

Answers: Naive Bayes

Answers to Q28-Q37.
A28. Naive Bayesian classification is a statistical classification method based on Bayes’ theorem. For a tuple X=(x₁,…,xₙ), it computes a score for each possible class Cᵢ and predicts the class with the highest posterior probability. It is “naive” because it assumes the attribute values are conditionally independent given the class.
A29. Bayes’ theorem gives P(Cᵢ|X)=P(X|Cᵢ)P(Cᵢ)/P(X). For a fixed observed tuple X, the denominator P(X) is the same for every class. So to find the largest posterior, it is enough to compare P(X|Cᵢ)P(Cᵢ).
A30. Class-conditional independence means that once the class label is known, the attributes are assumed independent. Thus P(X|Cᵢ)=P(x₁|Cᵢ)P(x₂|Cᵢ)…P(xₙ|Cᵢ). The class prior can be estimated by P(Cᵢ)=|Cᵢ,D|/|D|.
A31. Tutorial 3 P1: for class 1, score =P(A=1|1)P(B=2|1)P(C=2|1)P(1)=(2/4)(1/4)(1/4)(4/7)=1/56. For class 2, score =(1/3)(2/3)(2/3)(3/7)=4/63. Since 4/63>1/56, predict class 2.
A32. For X=(sunny,hot,high,false): yes score =(9/14)(2/9)(2/9)(3/9)(6/9). No score =(5/14)(3/5)(2/5)(4/5)(2/5). The no score is larger, so predict no. This agrees with the table row sunny,hot,high,false → no.
A33. For X'=(overcast,cool,high,true): yes score =(9/14)(4/9)(3/9)(3/9)(3/9). The no score contains P(overcast|no)=0, so without smoothing the no score is zero. Predict yes.
A34. For X=(sunny,cool,high,true): yes score =(9/14)(2/9)(3/9)(3/9)(3/9). No score =(5/14)(3/5)(1/5)(4/5)(3/5). The no score is larger, so predict no.
A35. In the 2023 table, there are five positive and five negative examples. For X=(A=1,B=1,C=0), positive score =(1/2)(3/5)(1/5)(1/5)=3/250. Negative score =(1/2)(2/5)(2/5)(1/5)=2/125=4/250. Since 4/250>3/250, predict negative.
A36. If one likelihood factor is zero, the whole product for that class becomes zero. In the exam, if no smoothing is specified, use the raw frequency estimate and let the score be zero. You can mention that this is a zero-frequency problem, but do not invent a smoothing method unless the question asks for it.
A37. P(C|X) asks: after seeing the attributes X, what is the probability of class C? This is the posterior we want for classification. P(X|C) asks: assuming the class is C, how likely are these attributes? Bayes’ theorem connects them, but they are not the same quantity.
09.05.2026A38-A40

Answers: Spelling Corrector + Checklist

Answers to Q38-Q40, plus final checklist.
A38. For a typed word w, the spelling corrector chooses the correction c that maximises P(c|w). By Bayes’ theorem, P(c|w)=P(w|c)P(c)/P(w). Since P(w) is the same for all candidate corrections, it chooses the c maximising P(w|c)P(c).
A39. P(c) is the language model: how likely the candidate correction is as an English word, estimated from word counts. P(w|c) is the error model: how likely someone would type w when they meant c. Candidate generation uses edit distance to generate plausible corrections near the typed word.
A40. Considering all possible strings is computationally too large and mostly useless. The shortcut is to prefer known words closest by edit distance: first the original known word at edit distance 0, then known words at distance 1, then known words at distance 2. Among candidates in the chosen set, select the word with the highest language-model probability.
