09.05.2026MAT700 Lecture 4 - distance measures

A. Distance Measures and Similarity

1. What a distance measure is

A distance measure is a function that takes two points in a space and returns a real number measuring how far apart they are.
Four axioms to memorise
These are the checklist for every “prove this is a distance measure” question.
Non-negativity
Distance cannot be negative.
Identity
Distance is zero exactly when the two objects are the same.
Symmetry
The distance from x to y equals the distance from y to x.
Triangle inequality
Going directly from x to y cannot be longer than going through z.

2. Vector distances

Manhattan / L1
Add absolute coordinate differences. Often less dominated by very large coordinate differences.
Euclidean / L2
Square differences, add them, then take the square root.
General Lr norm
A distance for r ≥ 1.
L∞ distance
Take the largest coordinate difference only.
Exam trap: when computing L∞, do not add the differences. Just take the maximum absolute difference.

3. Jaccard, cosine, edit, Hamming

Jaccard distance for sets
This is 1 minus Jaccard similarity. It is defined for sets, not bags.
Cosine angle idea
Used when direction matters more than length; e.g. scaled versions of the same vector may represent the same object.
Edit distance
Smallest number of single-character insertions and deletions needed.
Hamming distance
Count positions where two equal-length vectors differ.
Edit-distance example: abcde → acfdeg can be done in 3 operations: delete b, insert f after c, insert g after e. To prove the distance is exactly 3, you also need to justify that fewer than 3 operations cannot work.

B. Proof Templates for Distance Questions

1. Proving L∞ is a distance measure

Definition
Non-negative: every |x_i-y_i| is non-negative, so the maximum is non-negative. Identity: d∞(x,y)=0 means max_i |x_i-y_i|=0, so every coordinate difference is 0, hence x=y. Conversely, if x=y, all differences are 0. Symmetry: |x_i-y_i|=|y_i-x_i|, so the maximum is the same in either direction. Triangle inequality: for every coordinate i, |x_i-y_i|≤|x_i-z_i|+|z_i-y_i|. Taking maxima gives d∞(x,y)≤d∞(x,z)+d∞(z,y).
Memorise this shape: coordinate-level real-line triangle inequality → maximum over coordinates → L∞ triangle inequality.

2. Proving edit distance is a distance measure

Non-negative: a number of operations cannot be negative. Identity: zero operations are needed exactly when the strings are already the same. Symmetry: any sequence of insert/delete operations from x to y can be reversed from y to x by swapping insertions and deletions. Triangle inequality: take an optimal path from x to z and an optimal path from z to y. Concatenating them gives a valid path from x to y, so the smallest possible x→y path cannot be longer than that sum.
Triangle idea

B. Jaccard Distance Proof Template

Why this belongs in Lecture 4

Lecture 3 introduced Jaccard similarity, but Lecture 4/past papers ask for the distance-measure proof for Jaccard distance.
Jaccard distance
Minhash probability interpretation

Proof skeleton

Non-negative: Jaccard similarity is between 0 and 1, so 1−similarity is non-negative. Identity: dJ(A,B)=0 means SIM(A,B)=1, so the sets are equal. Symmetry: intersection and union are symmetric in A and B. Triangle inequality: use the minhash interpretation. Let events describe whether minhash values differ.
Probability union bound used in the proof
If h(A) differs from h(C), then h(A) differs from h(B) or h(B) differs from h(C). Therefore the event for A,C is contained in a union of the other two events.
Exam wording: “The hard part is the triangle inequality. Using minhash, Jaccard distance becomes the probability that two minhash values differ. The event that A and C differ is contained in the union of the events A differs from B and B differs from C. By the union bound, the required triangle inequality follows.”
Do not confuse: Jaccard similarity is not a distance. Jaccard distance is 1 − similarity.

C. k-Nearest Neighbour Classification

1. Core idea

kNN is an instance-based / lazy learner: it keeps the training data and classifies a new point by looking at nearby training examples. Find the k training instances closest to the unseen instance. Predict the most common class among those k neighbours.
Why distance matters: kNN only works after you choose a meaningful distance or similarity. Bad distance → bad neighbours → bad prediction.

2. Majority vote vs weighted vote

Common weighted-vote choice
A very close neighbour gets much more influence than a far neighbour.
Unweighted kNN
Each neighbour votes once. The majority class wins.
Weighted kNN
Each neighbour votes with a weight depending on distance. Sum weights by class.
Choosing k
The lecture says k affects behaviour; k can be selected using cross-validation.
k=1 issue
1NN has no training error on the training set but can give a wiggly boundary and poor future prediction.
Exam trap: in weighted kNN, do not count neighbours after choosing them. Add their weights class-by-class.

D. Model Evaluation and Selection

1. What we actually care about

Training error is not enough because it measures performance on data used to fit the model. Generalisation error is the expected misclassification rate on future data. A large independent test set can approximate generalisation error.
Overfitting: a very flexible model may fit noise rather than true signal. Lecture 4 gives the high-degree polynomial / wiggly boundary intuition.

2. Train / validation / test split

SetPurpose
TrainingFit the model.
Cross-validation / validationChoose parameters such as k in kNN.
TestFinal independent estimate of performance.
Lecture rule of thumb: 60% training, 20% cross-validation, 20% test.

3. Why accuracy can mislead

If the positive class is rare, a classifier can look accurate while failing to detect the rare class. The lecture’s cancer example motivates precision and recall: when the rare class matters, accuracy alone is not enough.
Exam wording: “Precision and recall are especially useful when the class of interest is rare.”

D. Precision, Recall and F-measure

1. Confusion matrix meanings

Actual positiveActual negative
Predicted positiveTP: true positiveFP: false positive
Predicted negativeFN: false negativeTN: true negative
Precision
Of the items predicted positive, how many were truly positive?
Recall
Of the truly positive items, how many did we find?
F-measure
Harmonic mean of precision and recall.

2. Proof that F ≤ average of precision and recall

Statement
Let P = precision and R = recall. Because (P−R)² ≥ 0, we have P² + R² ≥ 2PR. So (P+R)² = P²+2PR+R² ≥ 4PR. Divide by 2(P+R), assuming P+R>0, to get (P+R)/2 ≥ 2PR/(P+R)=F.
Memorise: this is just AM ≥ HM for two positive numbers, written in exam algebra.

E. Naive Bayesian Classification

1. What Bayesian classifiers are

Bayesian classifiers are statistical classifiers: they predict class-membership probabilities. For a new tuple X, the classifier compares the posterior probabilities of the possible classes.
Bayes theorem
Class prior from training data

2. Naive assumption

Naive Bayes assumes class-conditional independence: once the class is known, attribute values are treated as independent.
Product rule under the naive assumption
Classification rule
Why we compare scores: P(X) is the same denominator for every class, so for classification we compare P(C_i)P(X|C_i), not the full normalized posterior.

3. Estimating probabilities

For categorical attributes, estimate P(x_k|C_i) by counting training tuples with class C_i and attribute value x_k.
Pseudo-count / smoothing formula
Used when a count is zero; m_j is the number of possible values in attribute A_j.
Exam trap: without smoothing, one zero conditional probability makes the whole class score zero.

F. Spelling Corrector as a Bayesian Idea

1. Why this belongs here

The spelling corrector appears in Tutorial 3, but it is a Bayesian classification-style idea, so it belongs with Lecture 4 supplementary material. Given a typed word w, we choose the most likely intended correction c.
Bayesian spelling-correction rule
P(w) is ignored because it is the same for all candidate corrections.
Language model P(c)
How likely is c as an English word? Common words get higher probability.
Error model P(w|c)
How likely is the typed word w if the intended word was c?
Control mechanism argmax
Generate feasible candidate corrections and choose the candidate with the best combined probability score.
Example intuition: for a misspelling like “thew”, one candidate may be close by edit changes, while another may be much more common. The Bayesian split separates these two reasons.
Exam priority: likely conceptual only: state the rule and explain language model vs error model.

G. Mapped Tutorial 2 Worked Solutions I

Distance Measures P1-P3

P1. On non-negative integers, decide whether max(x,y), diff(x,y)=|x-y|, and sum(x,y)=x+y are distance measures.
max: not a distance, because d(x,x)=x, so for x=3, d(3,3)=3≠0.
diff: yes, this is the standard absolute-value distance on a line.
sum: not a distance, because d(x,x)=2x, so for x=5, d(5,5)=10≠0.
P2. Find L1, L2 and L∞ between x=(5,6,7) and y=(8,2,4).
Coordinate differences are |5−8|=3, |6−2|=4, |7−4|=3. Therefore L1=3+4+3=10, L2=sqrt(3²+4²+3²)=sqrt(34), L∞=max(3,4,3)=4.
P3. Hamming distances between x=000000, y=110011, z=010101, w=011100.
d(x,y)=4, d(x,z)=3, d(x,w)=3, d(y,z)=3, d(y,w)=5, d(z,w)=2.

Distance Measures P4-P5

P4. Prove L∞ is a distance measure.
Use the proof template earlier in this file: non-negative max of absolute values; zero iff all coordinates equal; symmetric by absolute value; triangle inequality from |x_i−y_i|≤|x_i−z_i|+|z_i−y_i| and taking maxima.
P5. Prove edit distance is a distance measure.
Use the proof template earlier: number of operations is non-negative; zero iff same string; reverse operation sequence for symmetry; concatenate x→z and z→y edit paths for triangle inequality.

kNN P1

P1. 1D data: x = 1.5, 2.5, 3.5, 4.5, 5.0, 5.5, 5.75, 6.5, 7.5, 10.5 with labels +,+,-,-,-,?,+,-,+,+. Classify x=5.5 using 1NN and 3NN; then weighted kNN.
1NN: nearest labelled point is 5.75 with label +, so class is +.
3NN majority: nearest labelled neighbours include 5.75(+), 5.0(−), and one of 4.5(−) or 6.5(−). Majority is −.
Weighted 3NN: positive weight = 1/(0.25)² = 16. Negative weight = 1/(0.5)² + 1/(1)² = 4+1=5. Weighted class is +.

kNN P2

P2. Weighted kNN with k=4 and L∞ distance for instance 7=(0.25,0.80). Training: 1(0.25,0.25)+, 2(0.25,0.75)+, 3(0.50,0.25)−, 4(0.50,0.75)−, 5(0.75,0.50)−, 6(0.75,1.00)+.
L∞ distances: d1=0.65, d2=0.05(+), d3=0.55, d4=0.25(−), d5=0.50(−), d6=0.50(+). Four nearest are 2,4,5,6.
Positive weight = 1/(0.05)² + 1/(0.50)² = 400+4=404. Negative weight = 1/(0.25)² + 1/(0.50)² = 16+4=20. So class(7)=+.

Model Evaluation P1

P1. 1000 emails: 100 spam, 900 not spam. TP=90 spam correctly classified; TN=700 not-spam correctly classified.
FN=100−90=10. FP=900−700=200. Precision=90/(90+200)=9/29. Recall=90/(90+10)=9/10. F=2PR/(P+R)=6/13.

Using the 2023 table: positive score = (1/2)(3/5)(1/5)(1/5)=3/250. Negative score = (1/2)(2/5)(2/5)(1/5)=2/125. Since 2/125 > 3/250, predict negative.

3. 2024 / 2025 kNN variant

Data: x = 1,4,9,16,25,36,49,64,81 with labels +,+,−,−,−,?,+,−,+. Classify x=36.
2NN majority: nearest neighbours are 25(−) and 49(+), so there is a tie unless a tie-breaking rule is given.
3NN majority: nearest are 25(−), 49(+), 16(−), so majority is −.
Weighted version: for 2NN, negative weight 1/11² is larger than positive weight 1/13², so class is −. For 3NN, adding the neighbour at 16 strengthens the negative class.

Classify X=(sunny, cool, high, true).

09.05.2026MAT700 Lecture 4 - memory page

Final Exam Memory Page

Must-write definitions

  • Distance measure: function satisfying non-negativity, identity, symmetry, triangle inequality.
  • kNN: classify unseen point using labels of k closest training instances.
  • Generalisation error: expected future misclassification rate, estimated using independent test data.
  • Precision: correctness among positive predictions. Recall: coverage of true positives. F-measure: harmonic mean of precision and recall.
  • Naive Bayes: choose class with largest posterior, assuming class-conditional independence.

Proofs to be able to reproduce

  • L∞ distance: four axioms, especially coordinate triangle inequality.
  • Edit distance: reverse paths for symmetry; concatenate paths for triangle inequality.
  • Jaccard distance: use minhash probability interpretation and union bound for triangle inequality.
  • F-measure inequality: (P−R)²≥0 ⇒ F≤(P+R)/2.

Common mistakes

  • Using training error as if it were test/generalisation error.
  • For L∞, adding differences instead of taking the maximum.
  • For weighted kNN, counting neighbours instead of summing weights.
  • Confusing FP and FN in the confusion matrix.
  • For Naive Bayes, comparing P(C|X) and P(X|C) as if they were the same.
  • For Naive Bayes, forgetting the prior P(C_i).
  • For Jaccard, proving similarity is a distance; the distance is 1−similarity.
