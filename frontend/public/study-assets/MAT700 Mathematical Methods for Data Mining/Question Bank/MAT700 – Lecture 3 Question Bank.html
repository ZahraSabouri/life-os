09.05.2026Lecture 3 question bank - answers A19-A24

Answers and Worked Solutions

A19. Shingling preserves local pieces of text. If two documents share phrases or sentences, they will share many shingles even if some words are changed or the order of sentences is altered.
A20. Lexical or character-level similarity asks whether two documents share the same text fragments. Semantic similarity asks whether they mean the same thing. Lecture 3 focuses on character-level/textual similarity, not meaning.
A21. If k is too small, unrelated documents share common shingles by accident. If k is too large, similar documents may share too few shingles. Good k is large enough that a given shingle is unlikely to appear by chance, but not so large that similarity disappears.
A22. The lecture notes discuss that possible shingles grow roughly exponentially with k. A simple rule uses about effective possibilities because characters are not equally likely. k=5 may work for emails; for large research articles, k=9 is considered safe.
A23. A characteristic matrix represents a collection of sets. Columns are sets. Rows are elements from the universal set. Entry (r,c)=1 if row element r belongs to set c, and 0 otherwise.

09.05.2026Lecture 3 - final drill

Final Exam Drill for Lecture 3

Last-hour drill: if you are out of time, memorise these answer skeletons and do the direct calculations.

Skeleton 1: Jaccard set calculation

1. Find the intersection. 2. Find the union. 3. Divide.
Set skeleton

Skeleton 2: Jaccard bag calculation

1. Make a count table. 2. Sum the minimum counts. 3. Divide by the sum of both bag sizes.
Bag skeleton

Skeleton 3: Bag proof ≤ 1/2

Let I be the sum of minimum multiplicities. Then I≤|B| and I≤|C|, so 2I≤|B|+|C|, hence I/(|B|+|C|)≤1/2.

Skeleton 4: Minhash theorem

Rows X = both 1, Y = exactly one 1, Z = both 0. Ignore Z. First relevant row gives equal minhashes exactly for X. Probability = |X|/(|X|+|Y|)=Jaccard similarity.

Common mistakes

Using ordinary set union for bags instead of the lecture convention |B|+|C|. Counting duplicate shingles twice when the question asks for a set of shingles. Forgetting to subtract the intersection when using |S∪T|=|S|+|T|-|S∩T|. Writing minhash as a deterministic exact similarity instead of a probabilistic estimator. Mixing Lecture 3 Jaccard similarity with Lecture 4 distance-measure proofs without saying it is a bridge topic.
