09.05.2026Lecture 1 question bank - answers 1-4

Answers / Worked Solutions

A1. Data mining is the process of extracting patterns from large datasets by combining methods from statistics and artificial intelligence with database management. The results of data mining are models or patterns. In an exam, include both the process and the output.
A2. Machine learning is the ability to teach a computer without explicitly programming it. In Lecture 1 wording, machine learning means learning models from data. Examples include car detection in images, handwriting recognition, spam filtering or predicting whether a user will like a movie.
A3. Machine learning is a good approach when we have little idea what pattern we are looking for, for example why a person likes or dislikes a film. It may not be the best approach when the goal can be described directly by hand-written rules, such as looking for obvious words and phrases in resumes.
A4. Supervised learning uses labelled data: each training instance has a designated target/label, and the aim is to predict that label for unseen instances. Example: spam/not spam or car/not car. Unsupervised learning uses unlabelled data: there is no target attribute, and the aim is to extract structure from the data. Example: clustering customers or finding association rules.
09.05.2026Lecture 1 question bank - answers 5-8

Answers / Worked Solutions

A5. Minimal exam-risk answer: semi-supervised learning uses both labelled and unlabelled data. Use it when some examples have known labels but many examples do not. Important honesty note: I cannot find a full semi-supervised definition in the mapped Lecture 1 slides, but it appears in the 2023 exam, so memorise this minimal definition.
A6. A labelled dataset has a specially designated attribute to be predicted. Data mining with labelled data is supervised learning. An unlabelled dataset has no specially designated target attribute; data mining with unlabelled data is unsupervised learning.
A7. Classification is supervised learning where the designated attribute is categorical, such as spam/not spam or car/bicycle/person. Regression, or numerical prediction, is supervised learning where the designated attribute is numerical, such as house price or share price.
A8. The five application types are: classification, which predicts a class label; numerical prediction/regression, which predicts a number; association, which discovers co-occurring items/events; clustering, which groups similar objects without labels; and ranking, which orders items by importance or relevance.

Answers / Worked Solutions

A9. Bonferroni’s principle warns against overzealous data mining. If we search a large amount of data for events of a certain type, some such events will occur even if the data is random. We should calculate the expected number of random occurrences first. If this number is much larger than the number of real instances we hope to find, then most discovered patterns are likely to be bogus statistical artefacts.
A10. The Total Information Awareness example considers mining huge amounts of credit-card receipts, hotel records, travel data and other information to detect terrorist activity. The Bonferroni warning is that, if the search pattern is not narrow enough, innocent activities may look suspicious just by chance. The more data we search, the more random-looking suspicious matches we should expect.
A11. For K objects in N boxes, define an indicator variable for each chosen m-tuple: it is 1 if all m objects are in the same box and 0 otherwise. A15. In statistics, data is often collected to answer a specific question. In data mining, the data is usually already collected for another purpose, such as retail transactions, and then mined for useful models or patterns. Data mining also often works with much larger datasets: millions or billions of records rather than hundreds or thousands.

Answers / Worked Solutions

A17. The curse of dimensionality is the exponential growth in the number of unit cells in the data space as the number of variables increases. In exam wording: adding more features does not simply make the problem slightly larger; it can make the search space grow exponentially, making reliable pattern discovery and exhaustive search much harder.
A18. With many variables, there is a high probability of finding some variable that correlates with a target variable Y even if no real relationship exists. This is why fake correlations appear in large searches, and why Bonferroni reasoning is needed before trusting discovered patterns.
A19. Lecture 1 says any computer programme is a function: it takes input and produces output. If we do not have a good theory, the data mining/ML task is to learn or approximate an unknown input-output function from observations. This motivates learning models from examples rather than explicitly programming every rule.
A20. A tabular dataset consists of examples, also called instances or samples. Each instance contains values of variables, often called attributes or features. A single table entry is the value of a feature for a given sample.
09.05.2026Lecture 1 question bank - answers 21-24

Answers / Worked Solutions

A21. An association rule describes items or events that occur together. Lecture 1 gives the example: IF cheese AND milk THEN bread, with probability 0.7. This means that, among cases satisfying cheese and milk, bread also appears with probability or confidence 0.7.
A22. An outlier or anomaly is a data object that does not comply with the general behaviour or model of the data. Some methods discard outliers as noise, but in applications such as fraud detection, text mining or social network analysis, rare events may be more interesting than regular events.
A23. Outliers may be detected using statistical tests that assume a probability model or distribution for the data. They may also be detected using distance measures, where objects far away from other points or clusters are treated as suspicious.
A24. Data preparation includes data cleaning, because real datasets may contain errors from measurement, judgement or equipment misuse; handling missing values, because real datasets often lack values for some attributes; and feature/dimension reduction, because irrelevant attributes increase computation and may worsen results.

Answers / Worked Solutions

A25. Storing too many attributes can be self-defeating because most attributes may be irrelevant to the prediction task. Lecture 1 uses the idea of predicting which supermarket customers will buy a new dog food brand: if we store 10,000 pieces of information about each customer, only a small number are probably relevant. Irrelevant features add computational overhead and may cause poorer results.
A26. Ideally, an image is a two-dimensional light intensity function , where x and y are spatial coordinates and the function value gives brightness or colour. A digital image approximates this continuous object by a two-dimensional array of discrete samples.
A27. A pixel, or pel, is one element of the two-dimensional array representing a digital image. Quantisation means that each sample amplitude is represented using a finite number of bits/grey levels. Too few grey levels can create visible contouring, especially on smooth ramps. Digital images are typically quantised to 256 grey levels.
