09.05.2026Lecture 2 question bank - answers 1-7

Answers - answers 1-7

Worked solutions and exam-style wording.
A1. A universe of objects is the full collection of objects of interest. An attribute or variable is a property of an object. A record or instance is the list of variable values for one object. A dataset is the complete available data for the application, often represented as a table whose rows are instances and columns are attributes.
A2. Labelled data has one attribute with special significance: the target to be predicted, e.g. MNIST image with digit label, or email with spam/not-spam label. Unlabelled data has no such target attribute, e.g. Netflix-style user/movie behaviour before choosing a prediction target.
A3. The universe is usually very large, while the observed dataset is only a small sample. Data mining assumes the observed data contains patterns that are useful for unseen objects. This is why the goal is not merely to describe the existing table, but to extract information that generalises.
A4. Instance-based learning stores examples and predicts by comparing a new instance with old examples using a similarity/distance measure. Model-based learning builds a model/function from examples and then uses that model for prediction. Instance-based learning is local and intuitive, but can require storing and comparing against many examples. Model-based learning is compact and faster at prediction time once a good function is learned.
A5. For each new item, instance-based learning may need to compare it with many or all stored training items. With millions or billions of examples, comparison becomes expensive; it also means the whole dataset may need to be stored or shipped with the system.
A6. Prediction assumes that the past is informative about the future. If future observations are unrelated to past data, then examples already seen cannot guide future decisions. The lecturer treats this as a basic assumption behind data science and machine learning.
A7. The model-based framework is: given training examples sampled from an unknown process, choose a decision function from a hypothesis space and evaluate it using a loss functional. The target is to minimise expected loss under the unknown generating process.

Answers - answers 8-14

Worked solutions and exam-style wording.
A8. The hypothesis space H is the class of functions/models we allow ourselves to choose from. It is our modelling choice: too small and it cannot represent the desired solution; too large and it can become hard to learn or overfit. In practice, model families often depend on parameters, so learning means finding good parameter values.
A9. A loss functional measures how bad a prediction/model is on an example. For house prices, the loss can measure the difference between predicted and actual sale price. For classification, a common loss is negative conditional log-likelihood.
A10. Ockham’s razor says we prefer the simplest hypothesis consistent with the data. In exam wording: if two models explain the data similarly well, choose the simpler one because it is less likely to fit accidental noise.
A11. In supervised learning each example is an input-target pair Regression has real-valued targets and commonly uses squared error: Classification has finite class labels and can use negative conditional log-likelihood:

A30. A document-term matrix represents a corpus as a matrix. Rows correspond to terms/words, columns correspond to documents, and an entry records the frequency or weight of that term in that document. In the vector space model, a document becomes a column vector of term weights.
A31. A33. A graph G=(V,E) has a finite nonempty set V of vertices/nodes and an edge set E of unordered vertex pairs. A loop is an edge from a node to itself. A simple graph is an undirected graph without loops. Adjacent vertices are joined by an edge. The order is |V| and the size is |E|.
A34. A directed graph has ordered pairs of vertices. A directed edge is an arc; the starting vertex is the tail and the ending vertex is the head. A weighted graph has a positive weight on each edge. Indegree counts incoming arcs; outdegree counts outgoing arcs.

Answers - answers 35-38

Worked solutions and exam-style wording.
A35. A walk from x to y is a sequence of vertices starting at x and ending at y with consecutive vertices connected by edges:A closed walk starts and ends at the same vertex. A trail has distinct edges. A path has distinct vertices, except possibly start/end. A cycle is a closed path of length at least 3. A shortest path has minimum length; its length is the graph distance, and is infinity if no path exists.
A36. Two vertices are connected if there is a path between them. A graph is connected if every pair of vertices is connected. A connected component is a maximal connected subgraph. A directed graph is strongly connected if directed paths exist between all ordered pairs; it is weakly connected if it becomes connected after ignoring edge directions.

09.05.2026Lecture 2 question bank - common mistakes and sources

Common Mistakes

1. Do not put TF-IDF in Lecture 1 revision. By the agreed map, TF-IDF and Tutorial 1 P2-P5 are Lecture 2.
2. For TF-IDF matrices, normalise term frequency column-by-column, then multiply row-by-row by IDF.
3. In the degree theorem, each undirected edge contributes exactly two degree-counts.
4. Unweighted adjacency uses 0/1; weighted adjacency uses weights; directed adjacency is not necessarily symmetric.
5. Cross entropy and softmax questions usually want definitions first, not just calculations.
6. The graph walk theorem is an induction proof; do not just state the result.
