A String is a Sequence

● A string is a sequence of characters. ● A sequence is an ordered collection of other values. ● Characters can be accessed one at a time with the bracket operator:

Indices

● The expression in brackets is called an index.

● The index is the offset from the beginning of the string. ● The first letter has an offset of zero.

NOTE that indices start at zero.

b a n a n a
0 1 2 3 4 5

More on Indices

● The value of the index has to be an integer.

>>> letter = fruit[ 1.5 ] Traceback (most recent call last): File "<stdin>", line 1, in <module> TypeError: string indices must be integers

More on Indices

● Negative indices allow us to work backward from the end of the string.

>>> last = fruit[ -1 ] >>> last ’a’

b a n a n a
-6 -5 -4 -3 -2 -1

len

● len is a built-in function that returns the number of characters in a string:

>>> fruit = ’banana’ >>> len( fruit ) 6

String Traversal

● Traversal: processing a sequence one element at a time, starting at the

beginning and continuing until the end.

index = 0 while index < len( fruit ):

letter = fruit[ index ] print( letter ) index = index + 1

Traversal with a for loop

● At each iteration of the loop, the next character in the string fruit is assigned

to the variable letter.

● The loop continues until no characters are left.

String Slices

● A segment of a string is called a slice. ● Selecting a slice is similar to selecting a character:

>>> s = “Monty Python” >>> s[ 0 : 5 ] “Monty” >>> s[ 6 : 12 ] “Python”

The Operator [ n : m ]

● The operator [ n : m ] returns the part of the string from the n-th character

to the m-th character, including the first but excluding the last.

● If the first index is omitted, the slice starts at the beginning of the string. ● If the second index is omitted, the slice goes to the end of the string.

>>> s = “Monty Python” >>> s[ : 5 ] “Monty” >>> s[ 6 : ] “Python”

The Operator [ n : m ]

● If the first index is greater than or equal to the second the result is an empty

string.

● An empty string:

– is represented by two quotation marks; – contains no characters and has length 0;

– is still a string.

>>> s = “Monty Python” >>> s[ 11 : 11 ]

''

>>> s[ 7 : 6 ]

''

Strings are Immutable

● Strings are immutable, which means that an existing string cannot be changed.

>>> greeting = ’Hello, world!’ >>> greeting[ 0 ] = ’J’ TypeError: ’str’ object does not support item assignment

Strings are Immutable

● The best you can do is create a new string that is a variation on the original.

>>> greeting = ’Hello, world!’ >>> new_greeting = ’J’ + greeting[ 1 : ] >>> new_greeting ’Jello, world!’

Methods

– It takes arguments and returns a value. ● A method is dffierent from a function:

String Methods

● upper() converts a string to upper case.

>>> word = ’banana’ >>> new_word = word.upper() >>> new_word ’BANANA’

String Methods

string.find( <value>, <start>, <end> )

● find searches the string for a specified value, and returns the index where it

was found.

● value : the value to search for in string. ● start : where to start the search (optional; default is 0) ● end : where to end the search (optional; default is the end of the string).

>>> word = ’banana’ >>> index = word.find( ’a’ ) >>> index 1 >>> word.find( ’na’, 3 ) 4

The in Operator

● in is a boolean operator that takes two strings. ● Returns True if the first appears as a substring in the second and False

otherwise.

>>> ’a’ in ’banana’ True >>> ’seed’ in ’banana’ False

Different string encodings

So far, we’ve been creating “ordinary” strings (using my_string = “some text”). Python supports different forms of character sequence, which single-letter prefixes can be used to create. Here are some to be aware of:

string Python’s built-in string type; allows escape sequences (\n, \t etc.) s = “text” A standard string representation. Supports Unicode (e.g. UTF-8).
raw string A string with no escape sequences (backslashes do not need to be escaped). s = r“C:\py” Useful for simply specifying file paths or regular expressions (more on “regular expressions” later...)
byte string A sequence of single bytes. Can represent text strings, or raw binary data. S = b”text” Useful for working with raw data (files, hardware streams etc.), and encoding/decoding text (UTF-8 etc.)

Different string encodings

Python’s string methods include encode() and decode(); we won’t look at string encodings right now, but it’s worth being aware of them as you may encounter them when importing and processing data.

>>> s = "Some text" >>> s

'Some text'

>>> s2 = s.encode( "UTF-8" ) >>> s2 b'Some text' >>> s2.decode( "UTF-8" )

'Some text'

>>> "C:\\Users\\Username\\Documents"

'C:\\Users\\Username\\Documents'

>>> r"C:\Users\Username\Documents"

'C:\\Users\\Username\\Documents'

Optional print Arguments

print( <input>, sep=<separator>, end=<suffix> )

print accepts several optional keyword arguments, which are useful for forming its output:

● input : the string(s) or object(s) to print (separated by commas; default: “”). ● separator : a string to be printed between each of the input(s) (default: “ ”). ● end : a string to be printed at the end of the line (default: “\n”).

>>> print( "abra", "ca", "dabra", sep = "-" ) abra-ca-dabra >>> print( "Origin: ", end = "" ) ; print( "unknown" ) Origin: unknown
