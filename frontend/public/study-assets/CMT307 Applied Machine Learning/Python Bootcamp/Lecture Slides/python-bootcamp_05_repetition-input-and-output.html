Sequence

● A sequence is the generic term for an ordered set. ● There are several types of sequences in Python. ● The most important are: strings, lists, tuples, and dictionaries.

The range Function

● The range() function returns a sequence of numbers, starting from 0 (by

default), and increments by 1 (by default), and stops before a specified number. ● For example:

– range( 4 ) returns the sequence of numbers: 0, 1, 2, 3.

The range Function

range( <start>, <stop>, <step> )

● start : Optional. An integer number specifying at which position to start.

Default is 0.

● stop : Required. An integer number specifying at which position to stop (but

not included in the sequence).

● step : Optional. An integer number specifying the increment at each step.

Default is 1. Examples:

– range( 3, 6 ) returns the sequence of numbers: 3, 4, 5. – range( 5, 10, 2 ) returns the sequence of numbers: 5, 7, 9.

Escape Sequences

Escape sequences allow you to put special characters into your strings.

\\ Backslash
\n Newline
\t Horizontal tab
\” Double quotation mark
