Boolean Expressions

● A boolean expression is an expression that is either True or False. ● == is a relational operator which compares two operands and produces True if

they are equal, and False otherwise.

● True and False are special values that belong to the type bool; they are not

strings.

>>> 5 == 5 True >>> 5 == 6 False >>> type( True ) <class ‘bool’> >>> type( False ) <class ‘bool’>

Relational Operators

== x == y x is equal to y
!= x != y x is not equal to y
> x < y x is greater than y
< x < y x is less than y
>= x >= y x is greater than or equal to y
<= x <= y x is less than or equal to y

Logical Operators

and x and y True only if x and y are both True
or x or y True if x is True, or y is True, or both are True
not not x Negates x. True only if x is False

Alternative Execution

● The Interpreter checks the condition. ● If the condition is True, body1 is run. Otherwise, body2 is run. ● Since the condition must be True or False, exactly one of the alternatives will run. ● The alternatives are called branches, because they are branches in the flow of

execution.

● Chained conditionals allow us to introduce more than two branches. ● Exactly one of the branches will run. ● elif is an abbreviation of “else if”. ● There is no limit on the number of elif statements that can be chained together. ● The else clause at the end is optional.

● Each condition is checked in order. ● If the first is False, the next is checked, and so on. ● If one of them is True, the corresponding branch runs and the statement ends. ● Even if more then one condition is True, only the first true branch runs.

● One conditional can also be nested within another. ● The outer conditional contains two branches (fi and else). ● The first branch contains a single, simple print statement. ● The second branch contains another if statement, which has two branches of its

own.

● Nested conditionals become difficult to read very quickly. ● Logical operators can often provide a way to simplify nested conditional

statements.
