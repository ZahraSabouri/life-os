A List is a Sequence

● A list is a sequence of values. ● A sequence is an ordered collection of other values. ● In a list, the values can be of any type. ● The values in a list are called elements, or sometimes items.

The simplest way to create a list is to enclose the elements in square brackets ( [ and ] ):

>>> numbers = [ 10, 20, 30, 40 ] >>> distros = [ “Knoppix”, “Debian”, “Gentoo” ] >>> mixed_types = [ “spam”, 2.0, 5, [ 10, 20 ] ]

Empty List

● A list that contains no elements is called an empty list. ● You can create one with empty brackets, [].

Nested List

● A list within another list is nested.

Assigning Lists

● Lists can be assigned to variables.

>>> cheeses = [ ’Cheddar’, ’Edam’, ’Gouda’ ] >>> numbers = [ 42, 123 ] >>> empty = [] >>> print( cheeses, numbers, empty )

[’Cheddar’, ’Edam’, ’Gouda’] [42, 123] []

Accessing Elements

● The elements of a list can be accessed using the bracket operator. ● Any integer expression can be used as an index. ● Reading or writing an element that does not exist, results in an IndexError. ● If an index has a negative value, it counts backward from the end of the list.

>>> cheeses[ 0 ] ’Cheddar’ >>> cheeses[ -1 ] ’Gouda’ >>> cheeses[ 10 ] IndexError: list index out of range

# Backwards: access the last list element

Lists are Mutable

● Lists are mutable (i.e. their elements can be changed individually). ● Elements can be reassigned.

>>> numbers = [ 42, 123 ] >>> numbers[ 1 ] = 5 >>> numbers

[42, 5]

● The in operator also works on lists.

>>> cheeses = [’Cheddar’, ’Edam’, ’Gouda’] >>> ’Edam’ in cheeses True >>> ’Brie’ in cheeses False

>>> ’Brie’ not in cheeses True

List Operations

● The + operator concatenates lists. ● The * operator repeats a list a given number of times.

>>> a = [ 1, 2, 3 ] >>> b = [ 4, 5, 6 ] >>> a + b

[1, 2, 3, 4, 5, 6]

>>> [ 0 ] * 4

[0, 0, 0, 0]

>>> a * 3

[1, 2, 3, 1, 2, 3, 1, 2, 3]

List Slices

● The slice operator also works on lists. ● If the first index is omitted, the slice starts at the beginning. ● If the second index is omitted, the slice goes to the end.

>>> t = [ ’a’, ’b’, ’c’, ’d’, ’e’, ’f’ ] >>> t[ 1 : 3 ]

[’b’, ’c’]

>>> t[ : 4 ]

>>> t[ 3 : ]

[’d’, ’e’, ’f’]

List Slices

● A slice operator on the left side of an assignment can update multiple

elements (i.e. only a segment of a list).

>>> t = [’a’, ’b’, ’c’, ’d’, ’e’, ’f’] >>> t[ 1 : 3 ] = [ ’x’, ’y’ ] >>> t

[’a’, ’x’, ’y’, ’d’, ’e’, ’f’]

● append adds a new element to the end of a list.

>>> t = [ ’a’, ’b’, ’c’ ] >>> t.append( ’d’ ) >>> t

List Methods

● extend takes a list as an argument and appends all of the elements to the

original list.

>>> t1 = [ ’a’, ’b’, ’c’ ] >>> t2 = [ ’d’, ’e’ ] >>> t1.extend( t2 ) >>> t1

[’a’, ’b’, ’c’, ’d’, ’e’]

● sort orders the elements of the list from low to high. ● It modifies the given list (this is called operating in-place).

>>> t = [ ’d’, ’c’, ’e’, ’b’, ’a’ ] >>> t.sort() >>> t

[’a’, ’b’, ’c’, ’d’, ’e’]

The sorted function

● sorted() is a build-in Python function. ● It can sort sequences (including lists), and returns a new object. ● It does not modify the given list.

>>> t = [ 'd', 'c', 'e', 'b', 'a' ] >>> u = sorted( t ) >>> u

['a', 'b', 'c', 'd', 'e']

>>> t

['d', 'c', 'e', 'b', 'a']

Other List Methods

Other list methods include:

● insert( <index>, <object> ): insert an object into the list before a given index. ● reverse(): reverses the order of elements in a list. Modfiies the given list. ● count( <value> ): returns the number of elements in the list with value <value>. ● index( <value> ): returns the first index in the list where the element <value>

appears.

Many have optional arguments (such as index(), which allows the specification of a start and stop position, so only a segment of the list may be searched).

Other List Methods

>>> a = [ 30, 10, 30 ] >>> a.insert( 2, 20 ) >>> a

[30, 10, 20, 30]

>>> a.reverse() >>> a

[30, 20, 10, 30]

>>> a.count( 30 ) 2

>>> a.index( 10 ) 2

The reversed function

● reversed(), like sorted(), is a build-in Python function. ● It can reverse sequences (including lists), and returns an iterator object which

can be converted to a list (which is also possible with range() ). ● It does not modify the given list.

>>> t = [ 'a', 'b', 'c', 'd', 'e' ] >>> u = reversed( t ) >>> u = list( u ) >>> u

['e', 'd', 'c', 'b', 'a']

>>> t

['a', 'b', 'c', 'd', 'e']

The reversed function

● Because it returns an iterator, reversed() can be used directly within a for

loop (just like range() ).

>>> t = [ 'a', 'b', 'c', 'd', 'e' ] >>> for c in reversed( t ):

... print( c ) ...

e d c b a

● pop removes the element at index <pos>. ● pop modifies the list and returns the element that was removed. ● If <pos> is not provided, the last element is deleted and returned.

>>> t = [ ’a’, ’b’, ’c’ ] >>> x = t.pop( 1 ) >>> t

[’a’, ’c’]

>>> x ’b’ >>> x = t.pop() >>> t [’a’] >>> x ’c’

Deleting Elements

● Removes the first item from the list whose value is <x>. ● It raises an error if there is no such item.

>>> t = [ ’a’, ’b’, ’c’ ] >>> t.remove( ’b’ ) >>> t

[’a’, ’c’]

● The del operator removes the element at the specified index from the list,

but the removed item is not returned.

● del can be used with a slice index to remove more than one element.

>>> t = [ ’a’, ’b’, ’c’ ] >>> del t[ 1 ] >>> t

[’a’, ’c’]

>>> t = [ ’a’, ’b’, ’c’, ’d’, ’e’, ’f’ ] >>> del t[ 1 : 5 ] >>> t

[’a’, ’f’]

Lists and Strings

● A string is a sequence of characters. ● A list is a sequence of values. ● A list of characters is not a string (it is a list!). ● The function list() can be used to convert from a string to a list of

characters.

>>> s = ’spam’ >>> t = list( s ) >>> t

[’s’, ’p’, ’a’, ’m’]

The split Method

● split breaks a string into its component words. ● separator : specifies the separator to use when splitting the string (optional:

by default any whitespace, “ “, is the separator).

● maxsplit : specifies how many splits to do (optional: default value is -1, which

is "all occurrences" ).

>>> s = ’hello, my name is Athena’ >>> t = s.split() >>> t

[’hello,’, ’my’, ’name’, ’is’, ’Athena’]

>>> t = s.split( "," ) >>> t

[’hello’, ’ my name is Athena’]

The is Operator

● The is operator checks whether two variables refer to the same object.

>>> a = ’banana’ >>> b = ’banana’ >>> id( a ) 140580986014640 >>> id( b ) 140580986014640 >>> a is b

True

● In this case, a and b are identical and, therefore, equivalent.

The is Operator

>>> a = [ 1, 2, 3 ] >>> b = [ 1, 2, 3 ] >>> id( a ) 140580985773504 >>> id( b ) 140580964882624 >>> a is b False

● In this case, a and b are equivalent but not identical.

Referencing and Aliasing

>>> a = [ 1, 2, 3 ] >>> b = a >>> b is a True

● The association of a variable with an object is called a reference. ● In this case, a and b refer to the same object. ● An object with more than one reference is aliased, i.e., it has more than one

name.

Aliasing and Mutability

● If the aliased object is mutable, changes made with one alias affect the

other.

● This behavior can be useful, however, it is error-prone, and care must be taken.

>>> a = [ 1, 2, 3 ] >>> b = a >>> b[ 0 ] = 42 >>> a

[42, 2, 3]

List Arguments

● When you pass a list to a function, the function gets a reference to the list. ● If the function modfiies the list, the caller sees the change (i.e. the given list

changes).

>>> letters = [ ’a’, ’b’, ’c’ ] >>> delete_head( letters ) >>> letters

[’b’, ’c’]

● The parameter t and the variable letters are aliases for the same object.

● It is important to distinguish between operations that modify lists and

operations that create new lists.

Modifying vs. Creating a List

● The append method modifies a list and returns None.

>>> t1 = [ 1, 2 ] >>> t2 = t1.append( 3 ) >>> t1

[1, 2, 3]

>>> t2 None

● The + operator creates a new list. The operand lists are unchanged.

>>> t3 = t1 + [ 4 ] >>> t1

[1, 2, 3]

>>> t3

[1, 2, 3, 4]
