Function Definition

A function definition specifies the name of a new function and the sequence of statements that run when the function is called. Until it is called, they do not run.

def quote_babbage():

● The first line of the function definition is called the header. ● The rest is called the body.

Header

● def indicates a function definition. ● quote_babbage is the name of the function. Function naming follows the same

rules as variable naming.

● The empty parentheses after the name indicate that this function doesn’t take

any arguments.

Body

● The body has to be indented. (By convention, indentation is usually four spaces.) ● The body can contain any number of statements.

● The strings in the print statements are enclosed in double quotes. ● Single quotes and double quotes do the same thing.

Function Object

Defining a function creates a function object, which has the type function.

>>> print( quote_babbage ) <function quote_babbage at 0xb7e99e9c> >>> type( quote_babbage ) <class ’function’>

The syntax for calling the new function is the same as for built-in functions.

Definition and Uses

● This program contains two function definitions: quote_babbage and

repeat_quote.

● Function definitions get executed just like other statements, but their effect is

to create function objects.

● The statements inside the function do not run until the function is called, and

the function definition itself generates no output.

● The function definition has to run before the function gets called.

Flow of Execution

● The flow of execution is the order statements run in.

● Statements are run one at a time, in order from top to bottom. ● Statements inside the function don’t run until the function is called. ● Function definitions do not alter the flow of execution of the program. ● Calling a function makes the flow of execution jump to the body of that

function.

Local Variables and Parameters

● A variable created inside a function is local. ● This means that the variables exists only inside that function. ● Parameters are also local. ● The space within which a variable exists (and so can be used) is called its

scope.

Local Variables and Parameters

>>> print_sum( 1, 2 ) 3 3 >>> print( res ) Traceback (most recent call last): File "<stdin>", line 1, in <module> NameError: name ’res’ is not defined

● Variable res is destroyed when print_sum terminates. ● a and b exist only inside of print_sum. ● Trying to access res, a or b outside of print_sum raises an error.

Why Functions?

● Creating a new function gives you an opportunity to name a group of

statements, which makes your program easier to read and debug.

● Functions can make a program smaller by eliminating repetitive code. Later, if

you make a change to that code, you only have to make it in one place.

● Dividing a long program into functions allows you to debug those parts one

at a time and then assemble them into a working whole.

● Well-designed functions are often useful for many programs. Once you write

and debug one, you can reuse it.

None

● Some functions (e.g., math functions) return a result. ● Their result can be stored in a variable for future use, e.g.,

a = math.log( math.e ).

● Void functions do not have a return value (e.g. our print_twice function). ● If you assign their result to a variable, you get a special value called None. ● The value None is not the same as the string ”None”. It is a special value that

has its own type:

>>> result = print_sum( 10, 10 ) 20 20 >>> print( result ) None >>> type( result ) <class ’NoneType’>

Return Values

● A function always generates a return value. ● If the function does not specify the value, None is returned.

● A return statement is used to end the execution of the function call and

return a result.

● <value> (optional) is returned to the caller.

docstring

● A docstring is a string at the beginning of a function within triple double

quotes (“””) that explains the interface.

● It contains the essential information someone would need to use this function.

– It explains concisely what the function does.

– It explains what effect each parameter has on the behavior of the function

and what type each parameter should be.

Lambda Functions

● Lambda functions are simple, compact functions. ● They can be quickly created inline without using the def keyword. ● Like normal functions, they can accept any number of arguments. ● Unlike normal functions, they can only contain one expression (i.e. they

cannot contain statements, fi/else, loops etc.).

● lambda returns a function object which can be assigned to a name, and can

be used immediately, or later.

● They are useful for making “map” functions in pandas (more on pandas later…)

my_function = lambda <arguments_list> : <return_expression>
