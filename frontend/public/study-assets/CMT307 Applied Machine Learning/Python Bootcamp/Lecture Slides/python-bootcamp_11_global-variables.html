Global Variables

● Variables that are created outside any function belong to a special scope called

__main__.

● Variables in __main__ are sometimes called global because they can be

accessed by any statement or function.

● Unlike local variables, which disappear when their scope ends, global

variables persist from one function call to the next.

verbose = True

if verbose:

print( ’Running example1’ )

Global Variables

Left: the variables a and b are in the __main__ scope (so they are globally available, even within mysum() and add() ).

The variables total, i, x and y are local to mysum(). They cannot be accessed outside of that function.

Different variables (also called x and y) are local to add(). They cannot be accessed outside of that function.

a and b can be directly read within mysum() or add(). But, to be written to

within those functions, they must be declared global within each function first.

● Reassigning a global variable inside a function results in unexpected behaviour. ● The Interpreter creates a new local variable with the same name as the

global one.

been_called = False

been_called = True

# WRONG

● To reassign a global variable inside a function, it must be declared before it’s

used.

● The global statement tells the Interpreter that the variable is global.

been_called = False

def example2():

global been_called been_called = True

# RIGHT

>>> example3() Traceback (most recent call last): File "<stdin>", line 1, in <module> File "<stdin>", line 2, in example3 UnboundLocalError: local variable ’count’ referenced before assignment

● Python assumes that count is local.

● The solution is to declare count global.

Global Mutable Variables

● The value of a global variable referring to a mutable variable can be

modified without declaring it.

● The variable must be declared global only if it is reassigned.

known = { 0 : 0, 1 : 1 }

def example4():

known[ 2 ] = 1

def example5():

global known known = dict()

# This is a mutable variable

# We’re NOT changing known’s value!

# - only an element of what it refers to

# We ARE changing known’s value!

# Thus, we _must_ declare it is global
