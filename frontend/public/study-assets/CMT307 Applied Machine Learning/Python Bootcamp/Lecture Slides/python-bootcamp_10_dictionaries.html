A Dictionary is a Mapping

● A dictionary is like a list, but more general. ● In a list, the indices have to be integers. ● In a dictionary they can be (almost) any type. ● A dictionary contains items, or key-value pairs. ● Each key is an index that is associated to a single value. ● In mathematical language, a dictionary represents a mapping from keys to

values.

● The function dict creates a new dictionary with no items. ● Curly braces, {}, represent an empty dictionary.

>>> eng2welsh = dict() >>> eng2welsh {}

Adding Items to a Dictionary

● Indexing with square brackets, [], can be used to add items to a dictionary. ● The output format is key : value.

>>> eng2welsh[ ’one’ ] = ’un’ >>> eng2welsh {’one’: ’un’}

● The output format, key : value, is also an input format. ● Non-empty dictionaries can be created by using the curly braces and providing

the items:

>>> eng2welsh = { ’one’: ’un’, ’two’: ’dau’, ’three’: ’tri’ } >>> eng2welsh {’one’: ’un’, ’three’: ’tri’, ’two’: ’dau’}

Dictionary Lookup

● Keys are used to look up the corresponding values in the dictionary. ● If the key isn’t in the dictionary, an exception is raised.

>>> eng2welsh[ ’two’ ] ’dau’ >>> eng2welsh[ ’four’ ] KeyError: ’four’

The len Function

● The len function returns the number of key-value pairs.

>>> len( eng2welsh ) 3

The in Operator

● The in operator tells whether something appears as a key.

>>> ’one’ in eng2welsh True >>> ’un’ in eng2welsh False

keys and values

● Method keys returns a collection of keys in the dictionary. ● Method values returns a collection of values in the dictionary. ● values can be used to see whether something appears as a value in a

dictionary.

>>> vals = eng2welsh.values() >>> ’un’ in vals True

Dictionary as a Collection of Counters

● You are given a string and you want to count how many times each letter

appears.

● A possible implementation using dictionaries is the following:

>>> h = histogram( ’bananas’ ) >>> h {’b’: 1, ’a’: 3, ’n’: 2, ’s’: 1}

● The method get takes a key and a default value. ● If the key appears in the dictionary, get returns the corresponding value;

otherwise, it returns the default value.

>>> h = histogram( ’a’ ) >>> h {’a’: 1} >>> h.get( ’a’, 0 ) 1 >>> h.get( ’c’, 0 ) 0

The clear Method

● The method clear removes all items from a dictionary. ● It takes no arguments.

>>> counts = { "a" : 5, "b" : 3 } >>> counts {'a': 5, 'b': 3} >>> counts.clear() >>> counts {}

● The dictionary method update takes a dictionary object and adds its key

value pairs to the existing dictionary.

>>> d = { 1: "one", 2: "three" } # Note: key “2” has value “three”! >>> d1 = { 2: "two", 3: "three" }

>>> d.update( d1 ) >>> d {1: ’one’, 2: ’two’, 3: ’three’} # Note: key “2” now has value “two”

Keys have to be Hashable

● A dictionary is implemented using a data structure called hashtable. ● Keys have to be hashable. ● A hash function takes a value and returns an integer (the hash value). ● Dictionaries use values to store and lookup key-value pairs. ● This system works fine if keys are immutable. ● Mutable types (like lists) are not hashable and cannot be used as keys. ● Dictionaries are mutable. They can be used as values but not as keys.
