Tuples are Immutable

● A tuple is a sequence of values.

– (Remember that a list is also a sequence of values.)

● The values can be any type, and they are indexed by integers. ● Tuples are very similar to lists. However, tuples are immutable.

Creating a Tuple

● A tuple’s output is a comma-separated list of values. ● It is common to enclose tuples in parentheses (but not required!). ● To create a single-element tuple, a final comma needs to be included.

>>> t = ’a’, ’b’, ’c’, ’d’, ’e’ >>> t = ( ’a’, ’b’, ’c’, ’d’, ’e’ )

>>> t1 = ’a’, >>> type( t1 ) <class ’tuple’> >>> t2 = ( ’a’ ) >>> type( t2 ) <class ’str’>

# A single-element tuple

# There’s no final comma; this is not a tuple!

Creating a Tuple

● Like dict() and list(), Python has a built-in function tuple().

– With no argument, it creates an empty tuple. – If the argument is a sequence (a string, list or tuple), the result is a

tuple containing the elements of that sequence.

>>> t = tuple() >>> t

()

>>> t = tuple( ’stem’ ) >>> t

(’s’, ’t’, ’e’, ’m’)

Bracket Operator and Slicing

● Most list operators also work on tuples. ● The bracket operator [] indexes an element. ● The slice operator selects a range of elements.

>>> t = ( ’a’, ’b’, ’c’, ’d’, ’e’ ) >>> t[ 0 ] ’a’ >>> t[ 1 : 3 ]

(’b’, ’c’)

Modifying an Element

● As tuples are immutable, elements can’t be modified. ● However, one tuple can be replaced with another.

>>> t[ 0 ] = ’A’ TypeError: object doesn’t support item assignment

>>> t = ( ’A’, ) + t[ 1 : ] >>> t

(’A’, ’b’, ’c’, ’d’, ’e’)

Tuple Assignment

● Swapping of variables:

>>> temp = a >>> a = b >>> b = temp

● More elegant solution using tuple assignment:

>>> a, b = b, a

Note that this works with all variables, notj ust tuples!

That is because tuples can contain any type of variable.

Tuple Assignment

● The left hand side is a tuple of variables. ● The right hand side can be any kind of sequence (string, list or tuple). ● The number of variables on the left and the number of values on the right

have to be the same.

>>> a, b = 1, 2, 3 ValueError: too many values to unpack >>> addr = ’me@mydomain.org’ >>> uname, domain = addr.split( ’@’ ) >>> uname ’me’ >>> domain ’mydomain.org’

Tuples as Return Values

● A function can only return one value. ● Returning a tuple effectively allows the function to return multiple values.

>>> t = divmod( 7, 3 ) >>> t

(2, 1)

>>> quot, rem = divmod( 7, 3 ) >>> quot 2 >>> rem 1

Tuples as Return Values

● Example of a function which returns a tuple:

def min_max( t ):

return min( t ), max( t )

Variable-length Argument Tuples (gathering)

● Functions can take a variable number of arguments. ● A parameter name that begins with * gathers arguments into a tuple.

Scattering

● Scattering is the complement of gathering. ● A sequence of values can be passed to a function as multiple arguments by

using the * operator.

>>> t = ( 7, 3 ) >>> divmod( t ) TypeError: divmod expected 2 arguments, got 1 >>> divmod( *t )

(2, 1)

● zip is a built-in function that takes two or more sequences and interleaves

them.

● The result is a zip object.

>>> s = ’abc’ >>> t = [ 0, 1, 2 ] >>> zip( s, t ) <zip object at 0x7f7d0a9e7c48>

The zip Function

● A zip object is a kind of iterator. ● An iterator is any object that iterates through a sequence. ● Indices cannot be used to select an element from an iterator.

>>> for pair in zip( s, t ):

... print( pair ) ... (’a’, 0) (’b’, 1) (’c’, 2)

● If the sequences are not the same length, the result has the length of the

shorter one.

>>> list( zip( ’Data’, ’Science’ ) )

[(’D’, ’S’), (’a’, ’c’), (’t’, ’i’), (’a’, ’e’)]

● A zip object can be easily converted into a list. ● The result is a list of tuples.

>>> list( zip( s, t ) )

[(’a’, 0), (’b’, 1), (’c’, 2)]

● Dictionaries have a method called items that returns a sequence of tuples,

where each tuple is a key-value pair.

● The result is a dict_items object, which is an iterator that iterates the key

value pairs.

● The items are in no particular order.

>>> d = { ’a’ : 0, ’b’ : 1, ’c’ : 2 } >>> d.items() dict_items([(’c’, 2), (’a’, 0), (’b’, 1)]) >>> for key, value in d.items():

... print( key, value ) ... c 2 a 0 b 1

● A list of tuples to can be used initialize a new dictionary.

>>> t = [ (’a’, 0), (’c’, 2), (’b’, 1) ] >>> d = dict( t ) >>> d {’a’: 0, ’c’: 2, ’b’: 1}

● Combining dict with zip yields a concise way to create a dictionary.

>>> d = dict( zip( ’abc’, range( 3 ) ) ) >>> d {’a’: 0, ’c’: 2, ’b’: 1}
