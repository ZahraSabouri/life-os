Definitions Section I: L1-L7

L1-L2: introduction, smoothing and decomposition

Time series
A sequence of observations indexed by time. The order is part of the data, so neighbouring observations may be related and should not be treated as a randomly permuted independent sample.
Smoothing
A method used to suppress noise and reveal the underlying signal or trend in a time series.
Decomposition
Splitting a series into interpretable components such as trend, seasonal component and residual/noise.
Forecasting
Using past observations and a fitted/estimated structure to predict future values.
Trend / seasonality / noise
Trend is long-term movement; seasonality is recurring behaviour over a fixed period; noise/residual is the leftover random variation.
Signal + noise model idea
The observed series is viewed as a useful underlying signal plus noise. Smoothing tries to estimate the signal by reducing the noise.
Source: ma3508_lecture1.pdf, p.1-p.20; ma3508_lecture2.pdf, p.1-p.15

L3-L4: stochastic process language and named processes

Stochastic process
A family of time-indexed random variables x_t(ω), where t belongs to a time set T and ω belongs to a sample space. For fixed t it is a random variable; for fixed ω it is a sample path.
Finite-dimensional CDF
F_{t1,...,tn}(u1,...,un)=P(x_{t1}≤u1,...,x_{tn}≤u_n). All such finite-dimensional CDFs fully describe the process.
Strict stationarity
All finite-dimensional distributions are invariant under a common time shift.
Wide-sense stationarity
The process has finite second moments, constant mean and covariance depending only on lag.
Gaussian process
Every finite linear combination of process values has a Gaussian distribution.
White noise
An iid process ε_t with mean m and variance σ²; Gaussian white noise has normal marginal distribution.
Random walk
x_t=ε_1+...+ε_t=x_{t-1}+ε_t, usually with zero-mean white-noise increments.
Brownian motion / Wiener process
W_0=0, continuous paths, independent increments, and W_s−W_t is normal with variance s−t for s>t.
Brownian bridge
B_t=W_t−tW_1 on [0,1], pinned at B_0=0 and B_1=0.
Poisson process
A counting process with P_0=0, Poisson distributed counts, independent increments and stationary increments.
Short/long memory
Short memory if ΣR(k) converges; long memory if the series diverges.
Spectral density
Frequency-domain representation of the covariance structure of a stationary process.
Source: ma3508_lecture3.pdf, p.2-p.19; ma3508_lecture4.pdf, p.2-p.18

L5-L7: spectral methods, prediction and estimation

Spectrum / spectral density
A function f(λ) describing how covariance/variance is distributed across frequencies.
Filtering
Transforming a series by a weighted combination of current and past/future values; in frequency terms, the filter changes the spectrum.
Periodogram
A sample-based estimate of frequency contribution, computed using sine/cosine sums or complex/FFT form.
Best linear predictor
The linear combination of observed values that minimises mean squared prediction error.
Estimator
A statistic computed from the observed sample and used to estimate an unknown theoretical quantity.
Correlogram
A plot of sample autocorrelations ρ̂(k) across lags.

Definitions Section II: L8-L15

L8-L13: ARMA, fitting, forecasting, ARIMA/SARIMA

Backward shift operator
B x_t = x_{t-1}. It lets ARMA equations be written compactly as a(B)x_t=b(B)ε_t.
AR(p)
Autoregressive process: current x_t depends linearly on p previous x-values plus white noise.
MA(q)
Moving-average process: current x_t depends on current and q previous white-noise terms.
ARMA(p,q)
A process combining AR(p) dependence in x-values and MA(q) dependence in white-noise innovations.
White-noise innovation
The new shock ε_t in the ARMA model, usually with mean 0 and variance σ².
Characteristic polynomials
a(z)=1−a_1z−...−a_pz^p for AR part; b(z)=1+b_1z+...+b_qz^q for MA part.
Causality
The process can be represented using present/past innovations only. In the lecture condition: a(z)≠0 for |z|≤1.
Invertibility
The innovations can be represented from current/past observations. In the lecture condition: b(z)≠0 for |z|≤1.
Yule-Walker estimation
Use sample autocorrelations in Yule-Walker equations to estimate AR coefficients.
h-step forecast
Prediction of x_{n+h} from observed data up to time n.
ARIMA(p,d,q)
ARMA model applied after d differences: a(B)(1−B)^d x_t=b(B)ε_t.
SARIMA
Seasonal ARIMA notation with ordinary differencing and seasonal differencing, using seasonal period s.

L14-L15: real-data workflow and SSA

Real-data workflow terms
Plot raw data, transform if needed, difference if needed, inspect ACF/PACF and periodogram, fit candidate models, compare outputs and forecast.
SSA
Singular Spectrum Analysis: a nonparametric method that builds a trajectory matrix, decomposes it, groups components and reconstructs interpretable signal components.
Trajectory matrix
A matrix made from lagged windows of the series. With series length N and window length L, K=N−L+1 and the trajectory matrix is L×K.
Window length
The chosen lag-window length L used to build the trajectory matrix.
Eigentriples/components
Components from the SVD decomposition of the trajectory matrix, used for grouping and reconstruction.
Grouping/reconstruction
Group selected components and reconstruct corresponding time-series parts such as trend or seasonality.
SSA forecasting
Forecasting based on the reconstructed/selected SSA components using course-supported recurrent or vector forecasting procedures.

Formula Cards I: Smoothing, Process Basics, Named Processes

Observed series model idea
observed series = signal + noise
Symbols: Signal is the underlying structure; noise is random disturbance.
Use when: Explaining L1/L2 motivation for smoothing.
Common trap: Smoothing estimates signal; it does not automatically forecast future values.
Simple moving average
S_k=(1/m)Σ_{i=0}^{m-1}x_{k-i}
Symbols: m is window length; x are observed values.
Use when: Smoothing noisy data using the previous m values.
Common trap: Large m is smoother but may miss local change; small m follows noise more.
Centred moving average
C_k=(1/(2m+1))Σ_{i=-m}^{m}x_{k+i}
Symbols: Uses points around time k.
Use when: Smoothing when future/nearby points are available for offline analysis.
Common trap: Cannot be used for real-time forecasting at the end without future values.
Weighted moving average
W_k=[1/Σw_j]Σw_i x_{k+i}
Symbols: w_i are weights.
Use when: When some nearby observations should count more.
Common trap: Weights must be normalised by their sum.
Simple exponential smoothing
E_k=αx_k+(1−α)E_{k−1}, 0<α<1
Symbols: α controls how fast the smoother reacts.
Use when: Smoothing with exponentially decreasing past weights.
Common trap: α near 1 reacts quickly; α near 0 is very smooth/sluggish.
Holt-Winters additive update
L_t=α(x_t−s_{t−m})+(1−α)(L_{t−1}+b_{t−1}) b_t=β(L_t−L_{t−1})+(1−β)b_{t−1} s_t=γ(x_t−L_t)+(1−γ)s_{t−m}
Symbols: L_t level, b_t trend, s_t seasonal component, m seasonal period.
Use when: Trend + seasonal smoothing as introduced in Lecture 2.
Common trap: Do not treat level, trend and seasonality as the same thing.
Finite-dimensional CDF
F_{t1,...,tn}(u1,...,un)=P(x_{t1}≤u1,...,x_{tn}≤u_n)
Symbols: t_i are time points; u_i thresholds.
Use when: Definition of full stochastic process description.
Common trap: One-dimensional distributions alone do not capture dependence.
Mean / variance / covariance
m(t)=E x_t σ²(t)=Var(x_t) R(t,s)=Cov(x_t,x_s)=E[x_tx_s]−m(t)m(s)
Symbols: t,s are time points.
Use when: Process calculations and WSS checks.
Common trap: Do not assume covariance is 0 unless independence/white noise is given.
Correlation
ρ(t,s)=R(t,s)/√(σ²(t)σ²(s))
Symbols: Normalised covariance.
Use when: Comparing dependence on −1 to 1 scale.
Common trap: Undefined if a variance is zero.
WSS condition
E x_t=m_0, Cov(x_t,x_s)=R(t−s)
Symbols: m_0 constant; covariance only depends on lag.
Use when: Checking weak stationarity.
Common trap: Strict stationarity is stronger and distributional.
White noise covariance
Cov(ε_t,ε_s)=σ² if t=s; 0 if t≠s
Symbols: σ² is innovation variance.
Use when: White-noise and ARMA calculations.
Common trap: White noise shocks are not the same as a random-walk path.
Random walk
x_t=Σ_{j=1}^{t}ε_j E x_t=0; Var(x_t)=tσ²; Cov(x_t,x_s)=min(t,s)σ²
Symbols: ε_j are zero-mean white-noise shocks.
Use when: Random walk definition/proof.
Common trap: Variance changes with t, so random walk is not WSS.
Brownian motion
W_0=0; W_s−W_t~N(0,s−t); Cov(W_t,W_s)=min(t,s)
Symbols: s>t for increments.
Use when: Wiener process definition and covariance.
Common trap: Independent increments, not independent levels.
Brownian bridge
B_t=W_t−tW_1; B_0=0; B_1=0; E B_t=0; Cov(B_t,B_s)=t(1−s), 0≤t≤s≤1
Symbols: Bridge is pinned at time 1.
Use when: Distinguish from Brownian motion.
Common trap: Covariance is not min(t,s).
Poisson process
P_t~Poisson(λt)
Symbols: λ is rate/intensity.
Use when: Counting process questions and renewal simulation.
Common trap: Stationary increments depend on interval length, not start time.
MA white-noise overlap example
y_t=(ε_t+ε_{t−1}+ε_{t−2})/3 R(0)=σ²/3, R(1)=2σ²/9, R(2)=σ²/9, R(h)=0 for h≥3
Symbols: h is lag.
Use when: Finite moving-average covariance calculations.
Common trap: Count overlapping identical ε terms only.

Formula Cards II: Spectral Methods, Prediction, Estimation

Discrete spectral density
R(k)=∫_{−π}^{π} e^{ikλ} f(λ)dλ
Symbols: R(k) covariance at integer lag k; f(λ) spectral density.
Use when: Converting spectrum to covariance.
Common trap: Use the lecture domain [−π,π] for discrete time.
Spectral density formula
f(λ)=1/(2π)Σ_{k=−∞}^{∞}R(k)cos(kλ)
Symbols: λ frequency; R(k) covariance.
Use when: Converting covariance to spectrum.
Common trap: Remember f(λ)=f(−λ), f(λ)≥0.
Continuous spectral representation
R(t)=∫_{−∞}^{∞}e^{itλ}f(λ)dλ
Symbols: t continuous lag; λ frequency.
Use when: Continuous-time spectral/covariance statement.
Common trap: Do not use [−π,π] for continuous-time formula.
Mercer covariance expansion
R(t,s)=Σ_{j=1}^{∞}λ_jφ_j(t)φ_j(s)
Symbols: λ_j eigenvalues; φ_j eigenfunctions.
Use when: Named expansion/theorem statement.
Common trap: Do not invent extra conditions beyond lecture wording.
Karhunen-Loeve expansion
x_t=Σ_{j=1}^{∞}ε_j√λ_j φ_j(t)
Symbols: ε_j random coefficients; λ_j, φ_j from covariance expansion.
Use when: Named expansion statement.
Common trap: Keep it as an expansion statement unless proof is requested.
Filter / convolution
y_k=Σ_{j=−∞}^{∞}q_jx_{k−j}
Symbols: q_j are filter coefficients.
Use when: Filtering signal/noise and frequency response.
Common trap: Filtering changes the series; it is not just plotting.
Filter spectrum relation
f_y(λ)=f_x(λ)f_q(λ)
Symbols: f_x input spectrum; f_q filter spectrum.
Use when: Frequency-domain filtering questions.
Common trap: Do not confuse input spectrum and filter spectrum.
Periodogram: trig form
T_c(λ)=1/√nΣx_jcos(λj), T_s(λ)=1/√nΣx_jsin(λj) P(λ)=T_c²(λ)+T_s²(λ)
Symbols: n sample size.
Use when: Manual/definition periodogram questions.
Common trap: Periodogram estimates spectrum; it is sample-based and noisy.
Periodogram: complex form
P(λ)=1/n |Σ_{j=1}^n x_j e^{iλj}|²
Symbols: e^{iλj} complex sinusoid.
Use when: FFT-based R code and compact formula.
Common trap: Take squared modulus, not ordinary square of complex number.
Best linear predictor
x̂_{n+h}=a_0+a_1x_1+...+a_nx_n
Symbols: h forecast horizon; a_i coefficients.
Use when: Linear forecasting setup.
Common trap: Coefficient values come from covariance, not arbitrary regression guessing.
MSE criterion
Ψ(a_0,...,a_n)=E(x̂_{n+h}−x_{n+h})²
Symbols: Mean squared prediction error.
Use when: Derive/define best linear predictor.
Common trap: Minimise expected squared error, not absolute error.
Coefficient solution
a=Γ^{-1}b_h, a_0=μ(1−Σa_j)
Symbols: Γ=(R(i−j)); b_h=(R(h+n−1),...,R(h))^T.
Use when: Best linear predictor calculations.
Common trap: Order of b_h matters; match lecture convention.
Prediction variance
σ²_{n+h}=R(0)−b_h^TΓ^{-1}b_h
Symbols: Variance/MSE of best linear prediction error.
Use when: Prediction interval/bounds questions.
Common trap: Must use same Γ and b_h setup as predictor.
Gaussian prediction bound
x̂_{n+h} ± z_{1−α/2} σ_{n+h}
Symbols: z critical value; σ prediction standard error.
Use when: Prediction interval under Gaussian assumption.
Common trap: Do not use sample sd blindly; use prediction error sd.
Sample mean
X̄_n=(1/n)Σ_{j=1}^{n}x_j
Symbols: Estimator of μ.
Use when: Estimation questions.
Common trap: Estimator differs from true μ.
Sample autocovariance/correlation
R̂(k)=1/nΣ_{j=1}^{n−k}(x_j−X̄_n)(x_{j+k}−X̄_n) ρ̂(k)=R̂(k)/R̂(0)
Symbols: k lag; hatted quantities from data.
Use when: Correlogram and fitting.
Common trap: Lecture uses denominator n in this estimator.
Mean CI from L7
X̄_n ± z_{1−α/2}√(2πf(0)/n)
Symbols: f(0) spectral density at zero.
Use when: Large-sample mean interval if lecture assumptions apply.
Common trap: Requires spectral-density estimate/condition; not a generic iid formula.

Formula Cards III: ARMA, Roots, Fitting and Forecasting

ARMA equation
x_t−a_1x_{t−1}−...−a_px_{t−p}=ε_t+b_1ε_{t−1}+...+b_qε_{t−q}
Symbols: a_i AR coefficients; b_j MA coefficients.
Use when: Identify ARMA(p,q) and write model equation.
Common trap: Do not put b terms on x side or a terms on ε side.
Backshift ARMA notation
a(B)x_t=b(B)ε_t a(B)=1−a_1B−...−a_pB^p b(B)=1+b_1B+...+b_qB^q
Symbols: B x_t=x_{t−1}.
Use when: Compact ARMA definitions and root checks.
Common trap: Root condition uses polynomial in z, not B values.
Causality condition
x_t causal iff a(z)≠0 for all |z|≤1
Symbols: a(z) AR polynomial.
Use when: Check if ARMA has causal representation.
Common trap: Roots must be outside the unit circle, not inside.
Invertibility condition
x_t invertible iff b(z)≠0 for all |z|≤1
Symbols: b(z) MA polynomial.
Use when: Check if innovations can be recovered from observations.
Common trap: Do not check AR polynomial for invertibility.
ARMA spectral density
f_x(λ)=σ² |b(e^{−iλ})|² / [2π |a(e^{−iλ})|²]
Symbols: σ² white-noise variance.
Use when: ARMA spectrum questions.
Common trap: Do not drop σ² or 2π.
MA(q) covariance
R(k)=σ²Σ_{j=0}^{q−|k|}b_jb_{j+|k|}, |k|≤q; R(k)=0, |k|>q
Symbols: b_0=1.
Use when: MA(q) covariance calculations.
Common trap: MA(q) cuts off after lag q.
Causal ARMA covariance
If x_t=Σ_{j=0}^{∞}c_jε_{t−j}, then R(k)=σ²Σ_{j=0}^{∞}c_jc_{j+|k|}
Symbols: c_j are MA-representation coefficients.
Use when: Covariance from infinite MA representation.
Common trap: Only use after causality/representation is valid.
Yule-Walker AR(p)
R(k)=a_1R(k−1)+...+a_pR(k−p), k>0 R(0)=a_1R(1)+...+a_pR(p)+σ²
Symbols: AR(p) covariance recursion.
Use when: AR covariance and parameter relationships.
Common trap: Include σ² only in the k=0 equation.
AR(1) MA(∞)
x_t=αx_{t−1}+ε_t ⇒ x_t=Σ_{j=0}^{∞}α^jε_{t−j}, |α|<1
Symbols: α AR coefficient.
Use when: Show causal AR(1) representation.
Common trap: Needs |α|<1.
AR(1) covariance/correlation
R(k)=σ²α^k/(1−α²), k≥0; ρ(k)=α^k
Symbols: α AR coefficient.
Use when: AR(1) covariance/autocorrelation questions.
Common trap: If α negative, autocorrelation alternates sign.
AR(2) causality inequalities
a_2+a_1<1, a_2−a_1<1, |a_2|<1
Symbols: For a(z)=1−a_1z−a_2z².
Use when: Fast AR(2) causality check.
Common trap: Do not reverse inequalities.
AR(p) MA coefficient recursion
c_0=1; c_j=a_1c_{j−1}+...+a_pc_{j−p}, c_k=0 for k<0
Symbols: c_j coefficients in causal MA(∞).
Use when: Compute MA representation and forecasts.
Common trap: Start with c_0=1.
ARMA mean with intercept
μ=c/(1−a_1−...−a_p)
Symbols: c intercept; μ mean.
Use when: Compute mean of ARMA with constant.
Common trap: MA terms vanish in expectation.
Yule-Walker estimator
â=Ĉ^{-1}v̂
Symbols: Ĉ=(ρ̂(i−j)); v̂=(ρ̂(1),...,ρ̂(p))^T.
Use when: Estimate AR(p) coefficients.
Common trap: Use sample correlations, not raw covariances, in Ĉ/v̂ as lecture states.
AR(2) estimators
â_1=ρ̂(1)(1−ρ̂(2))/(1−ρ̂²(1)) â_2=(ρ̂(2)−ρ̂²(1))/(1−ρ̂²(1))
Symbols: ρ̂(1),ρ̂(2) sample autocorrelations.
Use when: Repeated AR(2) fitting calculations.
Common trap: Denominator is 1−ρ̂²(1).
MA(1) fitting
b̂/(1+b̂²)=ρ̂(1), choose |b̂|<1; σ̂²=R̂(0)/(1+b̂²)
Symbols: b̂ MA(1) coefficient.
Use when: Invertible MA(1) estimation.
Common trap: Quadratic has two roots; choose invertible root.
AR(1) h-step forecast
x̂_{n+h}=μ+a^h(x_n−μ)
Symbols: a AR(1) coefficient.
Use when: AR(1) forecasting.
Common trap: For zero mean, μ=0 gives a^h x_n.
ARMA forecast via MA coefficients
x_j=Σc_iε_{j−i}; x̂_{n+h}=Σ_{i=0}^{∞}c_{i+h}ε_{n−i} MSE=σ²Σ_{i=0}^{h−1}c_i²
Symbols: c_i MA representation coefficients.
Use when: Causal ARMA forecasting and bounds.
Common trap: Unobserved future shocks have expectation zero.
ARIMA definition
a(B)(1−B)^d x_t=b(B)ε_t
Symbols: d number of differences.
Use when: ARIMA definition and differencing questions.
Common trap: ARIMA model is ARMA after differencing.
SARIMA definition
y_t=(1−B)^d(1−B^s)^D x_t a(B)ã(B^s)y_t=b(B)b̃(B^s)ε_t
Symbols: s seasonal period; D seasonal differencing.
Use when: Seasonal model notation.
Common trap: Keep ordinary and seasonal parts separate.

Log transform
y_t=log(x_t)
Symbols: x_t positive observations.
Use when: Stabilising changing variability in L14 workflow.
Common trap: Log is purposeful, not mandatory.

Proof Skeletons I: Stationarity, Covariance, Named Processes

1. Strict stationarity + finite second moments ⇒ WSS
1. Strict stationarity gives one-dimensional distributions unchanged by shifts, so the mean is constant.
2. Strict stationarity gives two-dimensional distributions unchanged by common shifts.
3. Use the covariance integral and shift both times by the same amount.
4. Choose the shift so the covariance depends only on t−s.
Conclusion: Mean is constant and covariance is a function of lag only, so the process is WSS.
Source: ma3508_lecture3.pdf, p.7-p.12
2. Covariance properties for WSS
1. R(0)=Cov(x_t,x_t)=Var(x_t).
2. ρ(0)=1 when R(0)>0.
3. Apply |Cov(X,Y)|≤√Var(X)√Var(Y). In WSS both variances are R(0), so |R(t)|≤R(0).
4. Use symmetry of covariance to show R(−t)=R(t).
Conclusion: These are quick validity checks for proposed covariance/correlation functions.
Source: ma3508_lecture3.pdf, p.11-p.14
3. Positive semidefinite covariance proof
1. Let ξ=Σc_ix_{t_i}.
2. Var(ξ)≥0.
3. Expand Var(ξ)=ΣΣc_ic_jCov(x_{t_i},x_{t_j}).
4. Under stationarity, Cov(x_{t_i},x_{t_j})=R(t_i−t_j).
Conclusion: ΣΣc_ic_jR(t_i−t_j)≥0 for all n, c_i and t_i.
Source: ma3508_lecture4.pdf, p.15-p.16
4. Positive semidefinite correlation proof
1. Start from covariance PSD.
2. If R(0)>0, define ρ(k)=R(k)/R(0).
3. Divide the PSD covariance double sum by positive R(0).
Conclusion: Correlation function is PSD whenever it is a normalised valid covariance function.
Source: ma3508_mock_exam.pdf, p.2; ma3508_mock_exam_solution.pdf, p.2
5. Random walk mean/variance/covariance
1. x_t=Σ_{i=1}^tε_i.
2. E(x_t)=ΣE(ε_i)=0.
3. Var(x_t)=ΣVar(ε_i)=tσ² because cross terms vanish.
4. For t≤s, x_t and x_s share ε_1,...,ε_t, so Cov(x_t,x_s)=tσ².
Conclusion: Random walk variance grows with time and it is not WSS.
Source: ma3508_lecture4.pdf, p.5-p.6
6. Moving-average white-noise covariance by overlap counting
1. Write both y_t and y_{t+h} as weighted sums of white-noise terms.
2. Expand Cov(y_t,y_{t+h}).
3. Cross terms with different ε indices vanish.
4. Count only overlapping identical ε terms and multiply by σ² and weights.
Conclusion: Finite MA covariance cuts off when there is no overlap.
Source: ma3508_lecture4.pdf, p.12-p.14
7. Random-phase sinusoid/cosine WSS template
1. Compute E(x_t). With Eξ=0, the mean is constant.
2. Since Var(ξ)=1 and Eξ=0, E(ξ²)=1.
3. Compute E(x_tx_s). Use sinA sinB or cosA cosB identities.
4. The uniform random phase kills the term involving A+B.
5. The remaining covariance is a cosine of λ(t−s).
Conclusion: Mean is constant and covariance depends only on t−s, so the process is WSS.
Source: ma3508_lecture3.pdf, p.11-p.12; ma0367_2015_exam-.pdf, p.4; ma0367_2016_exam_.pdf, p.4; ma0367_2019_exam_.pdf, p.4; ma0367_2020_exam_.pdf, p.4

Proof Skeletons II: Spectral, Prediction, ARMA

8. Best linear predictor normal equations
1. Define x̂_{n+h}=a_0+Σa_ix_i.
2. Minimise Ψ=E(x̂_{n+h}−x_{n+h})².
3. Differentiate with respect to a_i or use orthogonality of prediction error to observed variables.
4. Obtain Γa=b_h and solve a=Γ^{-1}b_h.
5. Use centring to get a_0=μ(1−Σa_i).
Conclusion: The best linear predictor coefficients are determined entirely by the covariance function.
Source: ma3508_lecture6.pdf, p.2-p.12
9. Prediction variance formula
1. Write the prediction error x_{n+h}−x̂_{n+h}.
2. Substitute optimal coefficients a=Γ^{-1}b_h.
3. Expand the MSE using covariance.
4. Simplify with Γa=b_h.
Conclusion: MSE=R(0)−b_h^TΓ^{-1}b_h.
Source: ma3508_lecture6.pdf, p.12-p.15
10. AR(1) MA(∞) representation
1. Start with x_t=αx_{t−1}+ε_t.
2. Substitute x_{t−1}=αx_{t−2}+ε_{t−1}.
3. Continue recursively: x_t=ε_t+αε_{t−1}+α²ε_{t−2}+...
4. Require |α|<1 for convergence.
Conclusion: Causal AR(1) equals an infinite MA with coefficients α^j.
Source: ma3508_lecture9.pdf, p.2-p.5
11. AR(p) coefficient recursion for MA representation
1. Assume x_t=Σc_jε_{t−j}.
2. Substitute into a(B)x_t=ε_t.
3. Match coefficients of ε_{t−j}.
4. Set c_0=1 and c_k=0 for k<0.
Conclusion: c_j=a_1c_{j−1}+...+a_pc_{j−p}.
Source: ma3508_lecture9.pdf, p.12-p.14; ma3508_lecture10.pdf, p.2-p.15
12. Yule-Walker AR(p) relation
1. Multiply the AR(p) equation by x_{t−k}.
2. Take expectations/covariances.
3. For k>0, the white-noise term is uncorrelated with past x values.
4. For k=0, the white-noise variance term σ² remains.
Conclusion: R(k)=a_1R(k−1)+...+a_pR(k−p), with σ² included only in the R(0) equation.
Source: ma3508_lecture9.pdf, p.9-p.11
13. Causality/invertibility root check
1. Write a(z) and b(z).
2. Solve roots of a(z)=0 for causality; roots must lie outside |z|≤1.
3. Solve roots of b(z)=0 for invertibility; roots must lie outside |z|≤1.
4. State conclusion separately.
Conclusion: Causality is about AR polynomial; invertibility is about MA polynomial.
Source: ma3508_lecture8.pdf, p.7-p.13; ma3508_lecture10.pdf, p.2-p.15
14. ARMA forecasting through MA coefficients
1. Use the causal representation x_j=Σc_iε_{j−i}.
2. Separate known past shocks from future shocks.
3. Conditional expectation of future shocks is zero.
4. Forecast uses known innovation terms; MSE uses omitted future-shock coefficients.
Conclusion: x̂_{n+h}=Σc_{i+h}ε_{n−i} and MSE=σ²Σ_{i=0}^{h−1}c_i².
Source: ma3508_lecture12.pdf, p.5-p.13
15. SSA trajectory → decomposition → reconstruction skeleton
1. Choose window length L and set K=N−L+1.
2. Build trajectory matrix X with x_{ij}=f_{i+j−1}.
3. Apply SVD to decompose X into elementary matrices.
4. Group selected components.
5. Reconstruct time-series components by hankelization/diagonal averaging as taught in the lecture workflow.
Conclusion: SSA extracts trend/seasonal/noise-like components without fitting ARMA equations.
Source: ma3508_lecture15.pdf, p.2-p.36

a(B)x_t=b(B)ε_t a(z)=1−a_1z−...−a_pz^p b(z)=1+b_1z+...+b_qz^q
Symbols: AR/MA polynomials.
Use when: ARMA definitions/root checks.
Common trap: AR polynomial has minus signs; MA has plus signs in lecture notation.
Root conditions
Causal iff a(z)≠0 for |z|≤1 Invertible iff b(z)≠0 for |z|≤1
Symbols: roots outside unit circle.
Use when: Causality/invertibility questions.
Common trap: Do not reverse inside/outside.
ARMA spectrum
f_x(λ)=σ²|b(e^{−iλ})|²/[2π|a(e^{−iλ})|²]
Symbols: σ² innovation variance.
Use when: ARMA spectral density.
Common trap: Do not omit σ² or 2π.
AR(1)
x_t=αx_{t−1}+ε_t R(k)=σ²α^k/(1−α²), ρ(k)=α^k x̂_{n+h}=μ+α^h(x_n−μ)
Symbols: α coefficient.
Use when: AR(1) covariance/forecast.
Common trap: Needs |α|<1 for stationary causal form.
Yule-Walker fitting
â=Ĉ^{-1}v̂; σ̂²=R̂(0)(1−Σâ_jρ̂(j))
Symbols: Ĉ sample correlation matrix.
Use when: AR(p) fitting.
Common trap: Use hatted estimates from data.
AR(2) quick estimates
â_1=ρ̂(1)(1−ρ̂(2))/(1−ρ̂²(1)) â_2=(ρ̂(2)−ρ̂²(1))/(1−ρ̂²(1))
Symbols: from ρ̂(1),ρ̂(2).
Use when: AR(2) fitting exam templates.
Common trap: Signs and denominator.
MA(1) fitting
b̂/(1+b̂²)=ρ̂(1), choose |b̂|<1
Symbols: invertible root.
Use when: MA(1) parameter estimate.
Common trap: Choose smaller absolute root.
ARIMA / SARIMA
ARIMA: a(B)(1−B)^d x_t=b(B)ε_t SARIMA: y_t=(1−B)^d(1−B^s)^D x_t
Symbols: d ordinary difference; D seasonal difference.
Use when: Definition/model notation.
Common trap: Differencing changes the series modelled.
