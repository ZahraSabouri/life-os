Lecture 14 plain-English workflow

1. Plot first
Before fitting anything, draw the series. The lecture says to plot the given time series xt and guess a model. The plot tells you whether there is trend, seasonality/cycle, changing variance, or unusual structure.
2. Think signal components
The lecture links real data back to Lecture 1: usually xt is the sum of a trend, seasonal/cyclical components, and an irregular/noise component.
3. Make the series more stationary if needed
If variance increases and xt>0, take yt=log(xt). If the mean is not constant, take differences yt=xt-xt-1. Airpass uses log then differences.
4. Use correlogram and periodogram
The correlogram helps guess AR/MA/cyclical behaviour. The periodogram helps identify frequencies with large contribution.
5. Fit, compare, forecast
Use arima() candidates, compare simple/low-variance/high-LL/low-AIC models, then use predict() and forecast intervals. If transformed, reverse the transformation carefully.

Lecture 14Workflow formulas

Lecture 14 - Formula and Idea Cards

Log transform
y_t = log(x_t)
Symbols: xt is the original positive series; yt is transformed.
Use when: Lecture says if Var(xt) is increasing and xt>0, take the logarithm.
Trap: Log transform is purposeful, not automatic for every dataset.
First difference
y_t = x_t - x_{t-1}
Use when: Lecture says if E xt is not constant, take differences.
Trap: Differencing changes what the series means: yt becomes a change, not a level.
Log-difference used for Airpass
y = diff(log(airpass[,3]))
Use when: Airpass becomes stationary after log and differencing.
Trap: Forecasts of y must be cumulated and exponentiated to return to passenger counts.
Periodogram in lecture code
I = |fft(x - mean(x))|^2 / n P = (4/n) I[1:(n/2)] ν = 0:(n/2-1)/n
Use when: To compute the scaled periodogram used in L14 plots.
Trap: Frequency ν=0 gives infinite period in 1/ν plots; interpret nonzero peaks.
Frequency to period
period = 1 / frequency
Use when: L14 plots period using 1/pgram[,1].
Trap: If frequency is 0.025, the period is about 40 observations.
Forecast band used in plots
prediction ± 1.96 × standard error
Use when: Lecture 14 plotting code draws pred+1.96*s.pred and pred-1.96*s.pred.
Trap: These are on the transformed scale unless you transform them back.
Reverse log-difference forecast
forecast level = exp(log(last observed level) + cumsum(pred))
Use when: Airpass forecast is first made for diff-log series and then returned to original scale.
Trap: Using exp(pred) alone is wrong because y is a difference of logs.
Model identification checklist
good model: small N, small σ̂², large LL, small AIC
Use when: Comparing candidate arima() models in Airpass, Earth Ocean and Nile examples.
Trap: Lowest noise variance alone is not the whole story; complexity and AIC matter too.

ACF/PACF and periodogram interpretation rules in L14

Correlogram rule: slightly damped oscillations suggest a significant cyclical component. Slow decrease suggests an AR(p) model may be relevant. Quick decrease suggests an MA(q) model may be relevant.
Earth Ocean example: the lecture says the ACF shows an oscillation with a period approximately 40, and slow decay for small lags indicates AR behaviour.
Periodogram rule: identify frequencies which have a large contribution; then convert frequency to period using the 1/frequency plot used in the lecture.

2) Airpass: ACF and periodogram

corrgram=acf(y,length(y),lwd=4)

Pgram=function(xts,title="time series")
{ n=length(xts); I = abs(fft(xts-mean(xts)))**2/n;
  P = (4/n)*I[1:(n/2)]; nu = c(0:(n/2-1))/n;
  plot(nu, P, type="l", xlab="Frequency",main=title,
       ylab="Scaled Periodogram"); return( cbind(nu,P) )
}
pgram=Pgram(y,"Periodogram of series y"); dev.new();
plot(1/pgram[,1], pgram[,2], type="l", xlab="Period" ,
     ylab="Scaled Periodogram",xlim=c(0,36))
Line-by-line: acf draws the correlogram; Pgram centres the data, uses fft(), scales the periodogram, creates the frequency grid, plots frequency against power, and returns a two-column table of frequency and periodogram values. The second plot converts frequency to period.
Exam adaptation: If asked to write periodogram R code, reproduce the Pgram structure: n, fft-centred data, squared modulus, scaled P, frequency vector, plot and return cbind(nu,P).

Lecture 15 plain-English explanation

SSA in one sentence
Singular Spectrum Analysis is a model-free way to decompose a time series into useful components such as trend, seasonal/harmonic structure and noise, and then use selected components for smoothing or forecasting.
The key trick
SSA turns a one-dimensional series into a matrix by sliding a window along the series. Once it is a matrix, SVD separates dominant patterns from smaller/noisy components.
The workflow
Choose window length L → build trajectory matrix X → decompose X by SVD → inspect eigentriples/eigenvalues → group useful components → reconstruct signal parts → forecast if needed.
How to think about components
The lecture labels components as trend, harmonic/seasonal, or noise. Leading eigentriples often capture large structure; later components often capture smaller corrections or noise.

Lecture 15SSA wording

Lecture 15 - Definitions to Write

Singular Spectrum Analysis (SSA)
SSA is a model-free methodology for the analysis of time series. In the lecture it is applied to discovery of structure, signal/trend extraction, smoothing/noise reduction, extraction of seasonal or harmonic components, forecasting and change-point detection.
Trajectory matrix
The trajectory matrix X is formed by applying a sliding window of length L to the series and writing each window as a column. For a series F=(f1,...,fn), X has L rows and n-L+1 columns.
Window length L
L is the number of observations inside each sliding window. The lecture states 2 ≤ L < n-L+1.
Eigentriple
In the SVD decomposition X = Σ √λi Ui ViT, (λi, Ui, Vi) is called an eigentriple. λi is an eigenvalue of XXT, Ui is an eigenfunction, and Vi is a factor vector.
Grouping and reconstruction
The lecture’s R code reconstructs the series by grouping eigentriples, for example Trend=c(1,4) and Seasonality=c(2:3,5:6). Reconstruction means forming selected signal components from chosen groups.
Series of finite rank
A time series F has rank d if the dimension of the linear space spanned by the columns of the trajectory matrix is d for any L>d and N-L>d, i.e. rank(F):=rank(X).
Series of finite order
A time series F has order d if there are functions φ1,...,φd and ψ1,...,ψd such that fi+j=Σk=1d φk(i)ψk(j).
Series of finite difference dimension
A time series F has finite difference dimension d if it satisfies a linear recurrence fi+d=Σk=1d αk fi+d-k with αd≠0.
SSA forecasting
The lecture lists two SSA forecasting methods: recurrent forecasting and vector forecasting. Recurrent forecasting applies a linear recurrence formula recursively; vector forecasting extends the trajectory matrix through the signal subspace.
Source: ma3508_lecture15.pdf, p.2, p.9-p.15, p.26-p.30, p.33-p.36
Lecture 15SSA formulas

Lecture 15 - Formula Cards

Trajectory matrix dimensions
K = N - L + 1 X is L × K
Symbols: N or n is series length; L is window length; K is number of windows/columns.
Use when: Asked to construct or state the size of the SSA trajectory matrix.
Trap: Do not make X an N×L matrix; columns are sliding windows.
Trajectory matrix entries
X = [x_{ij}], x_{ij}=f_{i+j-1} i=1,...,L; j=1,...,K
Use when: Building the matrix from a small series.
Trap: The next column shifts by one observation, not by L observations.
SVD decomposition
X = √λ₁ U₁V₁ᵀ + √λ₂ U₂V₂ᵀ + √λ₃ U₃V₃ᵀ + ...
Symbols: (λi,Ui,Vi) is an eigentriple.
Use when: Explaining how SSA decomposes the trajectory matrix.
Trap: Do not omit the square root on λ in the lecture’s SVD form.
Variance explained
λ_i / Σ_{j=1}^{L} λ_j
Use when: Interpreting how important the i-th component is.
Trap: This is about eigenvalues, not raw component amplitudes.
Series decomposition idea
F = F₁ + F₂ + F₃ + ...
Use when: Explaining trend/harmonic/noise components after SSA.
Trap: Components are reconstructed from matrix components; SSA is not ARMA modelling.
Finite-order representation
f_{i+j} = Σ_{k=1}^{d} φ_k(i) ψ_k(j)
Use when: Stating the lecture’s finite order definition.
Trap: This is an SSA theory definition, not an AR(p) model equation.
Finite-difference recurrence
f_{i+d}=Σ_{k=1}^{d} α_k f_{i+d-k}, α_d≠0
Use when: Stating finite difference dimension.
Trap: The recurrence is deterministic-series structure in SSA theory.
Recurrent SSA forecast
s̃_j = -(a₁s̃_{j-1}+...+a_{L-1}s̃_{j-L+1})/a_L
Use when: Explaining recurrent forecasting from the lecture.
Trap: Apply recursively to the reconstructed signal Ŝ, not blindly to raw noisy data.
Vector forecasting headline
Add h+L columns → hankelization → remove last L elements
Use when: Summarising the L15 vector forecasting algorithm.
Trap: Vector forecasting is not the same as simply applying an AR recurrence.
Source: ma3508_lecture15.pdf, p.9-p.15, p.26-p.30

Lecture 15 - Worked Examples and Algorithm Skeletons

Example A: trajectory matrix for f1,...,f9 with L=3

Question type: Construct the trajectory matrix for a short series using the lecture’s sliding-window rule.
Method: each column is a length-3 window. For f1,...,f9, L=3 and K=9-3+1=7.
X = [ f1 f2 f3 f4 f5 f6 f7 f2 f3 f4 f5 f6 f7 f8 f3 f4 f5 f6 f7 f8 f9 ]
Final answer: a 3×7 trajectory matrix.
Common trap: writing rows as disjoint blocks [f1 f2 f3], [f4 f5 f6], ... . SSA uses overlapping sliding windows.

Example B: interpreting eigentriples

Question type: Explain what an SSA decomposition plot/eigentriple grouping means.
Lecture model: SVD gives components. The lecture labels Fi as possible trend, harmonic or noise components. Examples show leading eigentriples extracting rough/fine trend, groups extracting seasonality, and later components reducing noise.
Exam answer shape: “Large leading components usually carry main structure; paired components may represent seasonal/harmonic behaviour; reconstruction from selected components gives trend/seasonality/smoothed signal.”
Source: ma3508_lecture15.pdf, p.10-p.11, p.18-p.25

Example C: SSA forecasting method choice

Question type: Name and describe the two SSA forecasting methods.
Answer: L15 lists recurrent forecasting and vector forecasting. Recurrent forecasting constructs an LRF and applies it recursively to the reconstructed signal. Vector forecasting adds new columns belonging to the signal subspace, adds h+L columns for an h-step forecast, performs hankelization, and removes the last L elements to obtain the forecast.
Common trap: using outside SSA terminology. Stick to the lecture words: recurrent forecasting, vector forecasting, signal subspace, hankelization.

L14-L15Exam traps

Common Mistakes

Lecture 14 workflow mistakes

  • Fitting too early: applying ARMA/ARIMA to raw data without first plotting and checking stationarity/variance.
  • Log transform confusion: treating log as mandatory. The lecture uses it when variance increases and xt>0.
  • Differencing confusion: forgetting that yt=xt-xt-1 changes levels into changes.
  • ACF/PACF overconfidence: the lecture says ACF/PACF help guess models, not prove a model is final.
  • Periodogram mistake: reading frequency peaks without converting to period when the exam asks about seasonal period.
  • Model selection mistake: choosing only the largest LL or only the smallest σ̂² without considering parameter count and AIC.
  • Forecast back-transform mistake: for Airpass, using exp(pred) instead of exp(log(last)+cumsum(pred)).
  • R code copying: copying se.fit or column indexes without checking the dataset structure.

Lecture 15 SSA mistakes

  • Trajectory matrix shape: forgetting K=N-L+1 and making the wrong matrix size.
  • Non-overlapping windows: constructing columns as disjoint blocks instead of sliding windows.
  • SSA vs ARMA: treating SSA decomposition as an ARMA model. The lecture says SSA is model-free.
  • Window length: choosing L without understanding that it controls the embedding/window in the trajectory matrix.
  • Eigentriples: forgetting that (λi,Ui,Vi) is the eigentriple and that λi/Σλj is variance proportion.
  • Forecasting methods: mixing recurrent forecasting and vector forecasting. Recurrent applies an LRF; vector extends columns in the signal subspace.
  • Rssa version issue: assuming forecast() always has the same arguments; the lecture explicitly warns about forecast/rforecast/vforecast differences.
Source: ma3508_lecture14.pdf, p.2-p.26; ma3508_lecture15.pdf, p.2-p.36
