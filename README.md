# Life OS

Fresh runnable spine for Life OS: Express + SQLite backend, Vite + React frontend,
and the first capture-to-list loop.

## Day-to-day dev

Terminal 1:

```powershell
cd code/life-os/backend
npm.cmd run dev
```

Terminal 2:

```powershell
cd code/life-os/frontend
npm.cmd run dev
```

The backend defaults to `dev-token-change-me`. For real use, copy each
`.env.example` file to `.env` and set the same private token in both places.
